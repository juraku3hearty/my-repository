# Xアカウント「連続ドラマ型・90日構成」運用キット

『普通を取り戻すまでの物語』——子どもを守るために人生を立て直した一人の母親の連続ドラマを、90話でひとつの作品として設計・運用するための資産一式。

## コンセプト（3行）

- 「被害者アカウント」ではなく「普通を取り戻す物語」。
- 副業は目的ではなく「逃げる選択肢を持つための手段」として静かに登場させる。
- 約90日は一切販売しない。積み上げるのは **信頼だけ**。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `01_90話マスタープロット.md` | 全90話のビート設計（Season1〜4）。各話に「出来事／会話／余韻」と伏線の張り・回収を割り当て済み |
| `02_伏線管理表.md` | どのDayで張り、どのDayで回収するかの一覧。回収漏れを防ぐ |
| `03_投稿テンプレート集.md` | 3段構成テンプレ／余韻の終わり方／NG例。毎回これに沿って書く |
| `04_運用カレンダー_投稿比率.md` | 投稿比率（過去20/気付き30/日常20/幸せ20/お金10）の管理と週次スケジュール |
| `05_Season1_下書き集.md` | Day1〜20の投稿ドラフト（そのまま出せる形／要事実確認箇所は明記） |
| `06_安全性_匿名運用ルール.md` | 裏垢としての匿名性・子ども・元配偶者リスク対策（最重要） |

## 使い方

1. **先に `06_安全性` を読む。** 実話ベースの裏垢は、身バレ・特定が最大のリスク。
2. `05_Season1_下書き集` を上から自分の実体験に照らして修正 → 予約投稿。
3. 投稿したら `02_伏線管理表` にチェック。回収予定を切らさない。
4. Season1が20話終わったら Season2 の下書きを追加作成する（同じ書式で拡張）。

## 絶対ルール（設計書より）

- 説明しすぎない／答えを書かない／最後は余韻で終わる。
- 一番言いたいことは書かない。読者が続きを想像できる終わり方をする。
- 相手を悪く描くより、主人公の感情と読者の想像力を大切にする。
- **事実は実体験ベース。現在進行形でない出来事を「今起きている事実」として創作しない。** 匿名性・安全性のために細部は編集する。
- 目標は「バズる投稿」ではなく「90話読み終えたとき、この人を応援したいと思われるブランド」。
