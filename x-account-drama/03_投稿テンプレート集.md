# 投稿テンプレート集

毎回このテンプレに沿って書く。**説明しない・答えを書かない・余韻で終わる。**
文字数 200〜350字。改行多め。感情は書きすぎない。

---

## 基本テンプレ：3段構成

```
【出来事】1〜2行。情景で書く。説明しない。

【会話】相手か自分の短いセリフ。「」を効果的に。

【余韻】言い切らない。読者に想像させて終わる。
```

### 例

```
体調が悪かった。

「病院行けば?」

欲しかったのは
「大丈夫?」の
一言だった。
```

---

## 余韻の終わり方・型（コピペで使える語尾集）

答えを書かず、続きを想像させる終わり方。**一番言いたいことは書かない。**

- 「理由は、まだ書けない。」
- 「この日を境に、私の考え方が変わった。」
- 「それが何だったかは、また今度。」
- 「あの一言が、私を動かした。」（何を、は書かない）
- 「気付いたときには、もう遅かった。」
- 「今なら分かる。あれは__だったと。」（__は伏せる）
- 「私はまだ、動けなかった。」
- 「続きは、また話します。」（Season締め用）

---

## 伏線を「張る」テンプレ

出来事を書かず、**存在だけ**を置いて終える。

```
あの日、
人生で一番つらい決断をした。

（終わり）
```

数日後に半分だけ開示：

```
あれは、
子どものことだった。

（まだ、何をしたかは書かない）
```

---

## 伏線を「回収」するテンプレ

過去に置いた一行を、読者が覚えている前提でそっと繋ぐ。説明で戻らない。

```
以前、
「一番つらい決断」と書いた。

あれは、
長女を先に家から出す、
という選択だった。
```

## 投稿タイプ別の書き分け

| タイプ | 目的 | 書き方のコツ |
|---|---|---|
| 過（過去の出来事）20% | 物語を進める | 事実だけ。相手を責めない。淡々と |
| 気（今の気付き）30% | 共感の核 | 過去→今の視点でひと言。説教しない |
| 子（子どもとの日常）20% | 守る動機・救い | 具体的な情景。あたたかさ |
| 幸（普通の幸せ）20% | 重さを抜く | お金のかからない小さな幸せ |
| 金（お金・考え方）10% | Season4の土台 | 売り込まない。「選べる自由」の話として |

## NG例（設計書の禁止事項）

| ❌ NG | ⭕ OK |
|---|---|
| 全部説明する | 一つだけ残して終える |
| 相手を罵る・責める | 事実だけを淡々と |
| 感情を書き尽くす | 情景で感じさせる |
| 1投稿で完結させる | 5〜10投稿に分割する |
| 現在進行形でない出来事を「今起きている」と書く | 過去は過去として書く |
| 毎日重い話 | 必ず日常（幸/子）を挟む |

---

## ハッシュタグ・運用メモ

- タグは付けすぎない。連続ドラマは「フォローして続きを追う」導線が主。多くて1〜2個。
- スレッド（ツリー）で1話ずつ繋ぐと、後から来た人が最初から読める。**Season区切りで固定ポスト更新**。
- プロフィールに「物語の入口です／90日、普通を取り戻すまでの記録」程度の一文。販売リンクは90日まで置かない。
