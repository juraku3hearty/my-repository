# 安全性・匿名運用ルール（最重要）

実話ベースの裏垢で最大のリスクは **身バレ・特定**。
特に、元配偶者・義実家に見つかること、子ども（特に長女）が特定されることは避けなければならない。
**バズより先に、この章を守る。**

---

## 1. アカウント設計での防御

- **既存アカウントと絶対に紐付けない。** 新規メールアドレス（普段使いと別）で作成。電話番号もできれば別。
- プロフィールアイコン・ヘッダーに、顔・自宅・院・地元が写った写真を使わない。イラストや風景（撮影場所が特定できないもの）にする。
- ユーザー名・ID に、本名・院名・地名・子どもの名前の断片を入れない。
- **本業（整骨院・SaaS・100チャレ）アカウントと相互フォロー/いいねしない。** 足跡から繋がる。
- 位置情報の付与を必ずオフ。写真のExif（位置情報）も投稿前に除去する。

## 2. 投稿内容での防御

特定に繋がる固有情報は、ぼかすか変える：

| ぼかす対象 | 対応 |
|---|---|
| 地名・駅名・院名・学校名/保育園名 | 書かない。「近所」「実家」で十分 |
| 具体的な日付・年 | 「あの日」「あの頃」に。現在進行形にしない |
| 子どもの人数・性別・年齢の正確な組み合わせ | 物語上必要な最小限に。長女＝「上の子」等でぼかす |
| 職業・勤務先が分かる描写 | 出さない。物語に不要 |
| 元配偶者・義実家の特定できる特徴 | 出さない。責めるほど特定リスクも上がる |
| 写真（家・車・持ち物・制服・景色） | 原則使わない。使うなら背景を確認 |

- **細部の編集はOK、事実の捏造はNG。** 起きたことの順序や感情は本物のまま、特定情報だけ変える。
- 現在進行形でない出来事を「今まさに起きている」と書かない（設計書の指示）。過去は過去として書く。

## 3. 子どもを守る

- 子ども本人が将来読んで傷つかない書き方をする。「守った記録」であって「晒し」にしない。
- 長女の避難など、安全に直結する話は、**時期や場所を絶対に特定させない**（今どこにいるか等は書かない）。
- 顔・名前・通う場所が分かる情報は一切出さない。

## 4. 元配偶者・義実家リスク

- **相手を罵らない**——設計書の方針であり、同時に法的・安全上の防御でもある（名誉毀損リスク・逆上リスクを下げる）。
- 「事実を淡々と」書く。感情は主人公の内面で描く。
- もし相手にアカウントを発見された/接触された気配があれば、**投稿を止めて相談を優先**。バズより安全。

## 5. アカウントを乗っ取られない

- 二段階認証を必ずオン。
- パスワードは本業と使い回さない。
- ログイン端末を家族と共有しない。

## 6. メンタル面の安全

- 過去のつらい出来事を書くのは、書き手自身がしんどくなることがある。
- **重い話を書いた日は、日常回（幸/子）を先に予約しておく**と、気持ちの逃げ場になる。
- しんどいときは投稿を止めていい。連続ドラマは「毎日」より「続く」ことが価値。

### この章の位置づけ

このドラマの最終目標は「90話読んで、この人を応援したいと思われるブランド」。
そのブランドを守るのが匿名性と安全性。**投稿を1本落とすより、特定される方がずっと痛い。** 迷ったら、書かない方を選ぶ。
