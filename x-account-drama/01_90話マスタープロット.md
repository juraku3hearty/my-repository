# 90話マスタープロット

全90話を「ひとつの連続ドラマ」として設計。
各話は原則 **①出来事 → ②短い会話 → ③余韻** の3段。
「🌱張る＝伏線を残す」「🎣回収＝過去の伏線を回収」。**毎話、最低1つ張り／1つ回収を意識する。**

投稿タイプの略号（比率管理用 → `04`参照）:
`過`=過去の出来事 / `気`=今の気付き / `子`=子どもとの日常 / `幸`=普通の幸せ / `金`=お金・考え方

## 90話の設計思想メモ

- **一番大きい伏線**は Day15「人生で一番つらい決断」。Day18で半開示、Day45/52で行動として現れ、Day71で全体像を言葉にする。**56日かけて回収する**のが連続ドラマの背骨。
- **「息を止める／息を吸う」**のモチーフを Day3 → Day14 → Day84 で通す。身体感覚のモチーフは説明せずに効く。
- **「大丈夫?の一言」**を Day24 で「欲しかった言葉」として置き、Day83 で「今なら自分が言える」と反転させる。
- 販売は90日まで一切しない。Day90 も「入口だけ」。売り込みは91日目以降、読者が「どうやって?」と聞いてきた状態で初めて。
