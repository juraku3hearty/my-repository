# 方針A｜AIウラカタ（あやねえ型）を本業にする

## 1. 決定事項

- **本業:** やりたいことのある人（経営者・個人事業主・チーム）の裏方作業を、GAS×LINE×スプレッドシート×AIで軽くし、**継続契約**で収入を作る
- **SaaS:** 本業の副産物。ウラカタ案件で繰り返し出てきた仕組みだけを製品化する。0→1のプロダクト開発を先に走らせない
- **100チャレ:** 無料の単発ではなく「継続の入口」と「公開ポートフォリオ」として運用する
- **Claudecord:** 継続契約の商品の一つとして位置づけ直す

## 2. MAYUの強み（本人の言葉から）

- 0→1は苦手
- やりたいことのある人の「穴」が見える
- 先回りした作業が無意識にできる
- 「このまま行くとここで引っかかる」が分かる

→ 教材の言葉に翻訳すると: **目的まで見ている／判断を相手に戻さない／小さなプラス1を返す**。これは愛され力の中核で、継続・紹介に一番効く部分。

**この型の最大リスク:** 無意識にやる先回りは、本人にとって「当たり前」なので値段をつけ忘れる。教材の失敗談（月10万契約で研修20万・謎の50万を自腹、実質赤字）はまさにこの型の人が落ちる穴。

**対策（運用ルール）:**
1. 先回りでやった作業は、その場で「やりました」と一言残す（見えない仕事を見える化）
2. 月次の業務報告書に必ず「頼まれていないが先に潰した穴」の欄を作る
3. 5〜10分で返せる先回りは返す。30分を超える先回りは「これ、やっておきましょうか？〇円です」と先に出す
4. 役割が増えたら、報酬・裁量・費用負担もセットで見直す。責任だけ増えたら止まる

## 3. ポジショニング

### 「何の人か」の一言（推奨: ①）

1. **「やりたいことがある人の裏方を、GAS×LINE×AIで軽くする人。先に引っかかる場所を見つけて潰します」**
2. 「整骨院の現場で回している、小規模事業者向けのAI業務自動化ウラカタ」
3. 「経営者の『あとでやろう』をLINEとスプレッドシートで自動化する人」

①を推奨する理由: 「先に引っかかる場所を見つける」がMAYU固有の価値で、他のAI自動化系と差別化できる。②は勝てる土俵（整骨院）を明示できるので、整骨院・治療院向けに発信する時はこちらを使う。

### プロフィール文（教材の型: 誰を・何で・どうサポート、特に何が得意）

> 整骨院スタッフ兼エンジニア。やりたいことのある経営者・個人事業主の裏方を、GAS・LINE・スプレッドシート・AIで軽くしています。
> 特に「このまま進めるとここで引っかかる」を先に見つけて、仕組みで潰すのが得意です。
> 自院で試験運用してから提供するので、机上の自動化ではなく現場で回るものだけを作ります。
> 実績: 献立AI（LINE Bot）、タイムカードOCR→裁判資料転記、動画の自動YouTube投稿。
> ご相談はこちら → （窓口URL）

**窓口を必ず入れる。** 現状の発信に依頼先が書いてあるか確認する。ない場合はLINE公式アカウントかGoogleフォームを1つ決めて全媒体に貼る。

### 発信の軸（第2章）

- 届けたい相手: 小規模事業の経営者・個人事業主。同業（AI自動化屋）ではない
- 投稿は「やったこと」より「なぜそうしたか」。例: 「弁護士案件で既存セルを上書きしない設計にした理由」
- 家庭・整骨院・独学の話は「言い訳」ではなく「価値観」として出す（現場で回している人、の証拠になる）
- 実績は依頼者の名前を借りて大きく見せない。相手の信用も預かっている

## 4. 100チャレの運用変更

### 募集文の改訂案

> **【100チャレ】あなたの「面倒な裏方作業」を、AIで1つ無料で自動化します**
>
> やりたいことはあるのに、毎日の事務・連絡・転記・投稿作業に時間を取られている方へ。
> 業務の流れを聞かせてもらい、「ここで引っかかる」という場所を1つ、GAS・LINE・スプレッドシート・AIで自動化します。
>
> - 費用: 無料（事例としてnoteで紹介させてもらうのが条件。社名・個人情報は伏せられます）
> - 対象: 経営者・個人事業主・チーム運営者
> - 流れ: 30分のヒアリング → 1週間以内に動くものをお渡し → 使い方の説明
> - できないこと: 大規模なシステム開発、既存の基幹システム改修
>
> 自動化した後、「これも」「あれも」となった場合は有料で継続対応します。
>
> 申込はこちら → （窓口URL）

変更点: 「引っかかる場所を1つ」で範囲を区切った／継続が有料であることを最初に書いた（第4章: 含む・含まないを先に見せる）／窓口を明示した。

### 案件ごとの10ステップ適用

100チャレでも第4章の型は省略しない。特に:

- ヒアリングで「何を作るか」より「何のためか」を先に聞く
- 開始時に一通で範囲・完了条件・納期を残す
- 納品時に「どこを見ればいいか」「設計のポイント」「次に引っかかりそうな場所」を添える
- 納品後に「すぐ隣の仕事」の種を一言置く（売り込まない）

### 完了3案件の「すぐ隣の仕事」

| 案件 | 今の状態 | すぐ隣の仕事（継続の種） |
|---|---|---|
| No.1 献立AI | セットアップ待ち | セットアップ代行（有料）／月次のメニュー傾向レポート／家族の好み学習の追加 |
| No.2 タイムカードOCR | 弁護士に連携済み | 次の裁判案件でのOCR再利用（案件単位で有料）／他の証拠書類のOCR化／事務所内の他の転記業務 |
| No.3 YouTube自動アップロード | 本番稼働中 | **月額の保守契約**（token失効対応、VPS監視、フォーム変更）／アップロード後のSNS告知自動投稿／視聴データの月次レポート |

No.3は既に保守作業（token.pickle更新）が発生している。これは無償で続けている限り「時給の範囲外でタダ働き」状態なので、最初の継続契約候補にする。

### 継続提案の文面（No.3向け）

> 動画アップロードの仕組み、無事に本番で回っていて嬉しいです。
> 1点だけ共有です。YouTube側の認証が数か月ごとに切れる仕様のため、その都度こちらで再設定が必要になります。
> 今後も止めずに使っていただけるよう、月額〇円で「認証の更新・サーバー監視・フォーム変更対応」をまとめてお引き受けする形をご用意しました。
> 急ぎではないので、必要になったタイミングでお声がけください。

## 5. Claudecordの位置づけ

現状: 初期6ヶ月 月15,000円 → 継続 月6,600円。前提としてClaude Max（$100/月）とVPSを顧客が自己契約。

方針Aでの整理:

- Claudecordは「AIウラカタの継続契約」の一形態として売る。売り物はBotではなく「MAYUが各VPSに入って面倒を見続けること」
- 料金の横に**含む・含まない**を明記する（第4章ステップ4）。例:
  - 含む: 初期構築、月次の動作確認、Claude Code更新対応、Discord設定変更 月〇回まで
  - 含まない: 顧客業務そのもののGAS開発（別途見積）、深夜・休日対応
- 6ヶ月後に6,600円へ下がる設計は「効率化したのに報酬が下がる問題」と同じ構造。下げるなら担当範囲も減らす。据え置くなら「継続で増える価値」（蓄積されたスキル・設定資産）を報告書で見せる
- 契約前に **面談前5条件** を顧客に提示する（下記）

## 6. 契約前チェック（MAYU用に埋める）

教材の「面談前に決める5条件」。空欄はMAYUが埋める。

| 条件 | MAYUの回答 |
|---|---|
| 稼働できる曜日・時間 | （整骨院の勤務と重ならない時間帯を記入） |
| 夜間・休日対応 | （可否。可なら追加料金の有無） |
| 最低報酬ライン | （継続は月〇円以上、スポットは〇円以上） |
| できる業務・できない業務 | できる: GAS/LINE/スプレッドシート/AI連携/VPS運用。できない: （デザイン、動画編集、大規模開発 など） |
| 絶対に譲れないこと | （家庭・整骨院の勤務・健康） |

黄色信号（契約前に見えたら慎重に）: 報酬の話を後回し／値下げ交渉が長い／条件を書面に残すのを嫌がる／「仲間として」と言いながら責任だけ増やす／前任者の悪口。

## 7. 月次業務報告書（MAYU版テンプレ）

継続契約の顧客に毎月送る。A4一枚、2〜3分で読める量。

```
【〇月 業務報告】〇〇様

1. 今月対応したこと
   ・
2. 成果・変化（相手の何が変わったか。時間・回数・ミスの減少で書く）
   ・
3. 改善したこと
   ・
4. 先に潰した穴（頼まれていないが、このまま行くと引っかかると判断して対応したもの）
   ・
5. 課題・確認したいこと
   ・
6. 来月の予定・提案
   ・
```

4番がMAYUの型に合わせた独自項目。ここが空の月はないはず。埋まらないなら先回りを無意識にやって記録し忘れている。

## 8. 直近でやること（優先順）

1. 窓口を1つ決めて、note・X・100チャレ募集文に貼る
2. No.3（ディオーネ）に保守契約の提案文を送る
3. 100チャレ募集文を改訂版に差し替える
4. 6章の5条件を埋める
5. Claudecordの「含む・含まない」を明文化する
6. 次の100チャレ案件から、納品文に「次に引っかかりそうな場所」を1行添える

## 9. 確定版｜実名（真弓）とリオの役割分担

**決定（2026-09-26）:** 発信の主体は **リオ**。真弓の実名アカウントは業者が管理しているため、そこでウラカタの発信はしない（業者を外すと投稿が自分の負担になるので外さない）。方向・一言ポジション・窓口は共通。

| | 真弓（実名） | リオ（rio-ai） |
|---|---|---|
| 役割 | 実在証明。紹介された人が検索した時に「整骨院で働いている実在の人」と分かればよい。100チャレの名義 | **発信の主体。** オンライン・知らない相手・有料商品（Brain、Claudecord）の入口 |
| 関わる相手 | 会社経営者・既存の横のつながり（弁護士、バレー団体、整骨院周り） | 経営者との直接の関わりはないが、同じ仕事を受ける |
| 発信 | 実名SNSは業者管理のまま触らない。100チャレの事例記事をnoteに案件ごとに書くだけ（定期投稿なし） | プロフィール・固定投稿・日々の発信をここに集中 |
| 整骨院の話 | 業者側に任せる | 出さない。「現場経験がある」程度 |
| 物語（範囲が溶けた話） | **書かない。** 真弓を知る人には相手が特定されるため | プロフィールに5行だけ置く（A案。ダンナとは書かない） |
| 窓口 | 共通のフォーム1つ | 同じフォーム |

前提: 両者は内容で紐づく。匿名性ではなくペンネームとして扱う。紐づいても困らない書き方にしておく。
未確認: 100チャレのnoteが業者管理外であること。業者管理なら100チャレ記事もリオ側で書く。
