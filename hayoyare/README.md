# 📢 ハヨヤレ — 上司の連絡を勝手に拾う関西弁おばちゃん（Slack専用）

上司からのSlack連絡を**全自動で**おばちゃんが聞き耳を立てて拾い、AIが「何を・いつまでに」を読み取って登録。
期限が近づくとDMで詰めてくる。手動登録ゼロ＝**拾い忘れが存在しない**。

## 動き

```
上司「例の資料、金曜までに頼むわ」（チャンネル or DM）
  → 5分おきの巡回がキャッチ、Geminiが依頼と判定して自動登録
    → おばちゃんからDM
       「👂 いま上司さんから来てたやつ、拾っといたで。📌 資料作成（期限: 8/22 18:00）
        登録しといたからな。違ってたら『ちゃう』て返しや」
  → 期限60分前から30分おきに催促（😗→😤→💢→👹の4段階）
  → 「やった」と返すと「🍬 ようやった。飴ちゃんあげるわ」で終了
  → 金曜17時、未完了があれば「📋 今週の宿題の棚卸しするで」
```

- 誤検知は「**ちゃう**」の一言で取り消し
- 「**リスト**」で一覧（**期限の早い順**・**誰から来たか**・**元メッセージの本文つき**。確認DMにも元本文を引用表示）
- 「**やった 2**」「**消して 2**」で番号指定の完了・削除
- 「**直して 2 期限は金曜15時**」でおばちゃんの間違いを修正（内容・期限どちらでも。修正後は催促もやり直し）
- 「**設定**」でいまの見張り体制、「**ヘルプ**」でコマンド一覧
- 上司には何も見えない（おばちゃんとのやり取りは自分とのDM内だけ）

## セットアップ

### 1. Slackアプリを作る（5分）

1. https://api.slack.com/apps → **Create New App** → From scratch → 名前「ハヨヤレ」、ワークスペース選択
2. 左メニュー **OAuth & Permissions** → Bot Token Scopes に以下を追加:
   - `chat:write` `im:write` `im:read` `im:history`
   - `channels:read` `channels:history` `groups:read` `groups:history` `users:read`
3. **User Token Scopes** に追加: `im:read` `im:history` `channels:read` `channels:history` `groups:read` `groups:history`
   （ユーザートークンがあると、Botをチャンネルに招待せずに「自分に見えている会話」を監視できる＝他のメンバーから完全に見えない。他人運営のコミュニティで自分用に使う場合はこの方式推奨）
4. ページ上部 **Install to Workspace** → 許可
5. **Bot User OAuth Token（xoxb-…）**をコピー（User Token Scopesを設定した場合は **User OAuth Token（xoxp-…）**も）
6. 監視したいチャンネルで `/invite @ハヨヤレ`（チャンネル監視する場合）

### 2. GAS設置（5分）

1. GASプロジェクト新規作成 →「ハヨヤレ」→ この7ファイルを貼り付け
2. スクリプトプロパティ:
   - `SLACK_BOT_TOKEN` = xoxb-…
   - `SLACK_USER_TOKEN` = xoxp-…（DM監視する場合のみ）
   - `GEMINI_API_KEY` = Google AI Studio のキー
3. `initialize()` 実行（権限承認。MY_SLACK_USER_IDはユーザートークンがあれば自動設定、無ければSlackプロフィール→メンバーIDを手動で設定）
4. `listMyChannels()` / `listMyDms()` を実行 → ログに出たIDから監視したい会話を選んで
   スクリプトプロパティ `WATCH_CHANNELS` にカンマ区切りで設定（例: `C0123ABC,D0456DEF`）
5. （任意）`BOSS_USER_IDS` に上司のメンバーID（U…）を設定。空なら自分以外の全員が対象
6. もう一度 `initialize()` → おばちゃんから着任DM「今日からあんたの上司の連絡、おばちゃんが見張っとくからな」が来たら完成

動作テスト: `testNag()` で今すぐ詰められる。実戦テストは監視チャンネルで誰かに「〇〇を明日までにお願い」と書いてもらい、5分以内に確認DMが来るか。

## 注意

- 初回巡回は「位置合わせ」だけ行い、過去ログには反応しない（設置した瞬間に過去の依頼で騒がない）
- DM監視はSlackの仕様上、自分のユーザートークン（自分の権限で自分宛DMを読む）が必要
- 会社のワークスペースでアプリ追加が制限されている場合は管理者の承認が必要
