# 辞書（ナレッジベース）

読んだ教材・記事・ノウハウを、後から検索・参照・AI壁打ちに使える形で構造化して保存する場所。

## 運用ルール

- 1ソース = 1ファイル。ファイル名は `YYYY-MM-DD_タイトル.md`
- 先頭に YAML front matter（title / source / author / type / tags / purchased）
- 構成は固定: **概要 → 用語定義 → 章別要点 → テンプレート → チェックリスト → 自分への適用メモ**
- 有料教材は全文転載しない。要点・構造・型のみを自分の言葉で残す（個人の学習用途。再配布禁止）
- AI に読み込ませて壁打ちする前提で、見出しと箇条書き中心に書く
