# クライアントワークの教科書（あやねえ）辞書

## 0. 概要（3行）

- **主張:** 次の依頼が来るかはスキルだけで決まらない。発注側は「この人に任せると自分の仕事が前に進むか」を見ている。
- **公式:** `収入 ＝ スキル × クライアントワーク力`。クライアントワーク力＝成果物以外の「仕事の進め方」の質。
- **構成:** 仕事になる前（SNS・オフ会）→ 案件中（10ステップ・テキスト術）→ 誰と組むか（クライアント選び）→ 信頼の換金（継続・紹介・単価・セカンドキャリア）→ 全部を回す仕組み（タスク管理）。

著者プロフィール要点: 大手ゲーム会社の事務職 → 時給1,500円のオンライン秘書 → 11か月で月収100万円 → 過労で倒れ働き方を再設計 → 3児（双子含む）の母、稼働1日3〜5h、受注6年・発注5年、審査制の秘書講座主宰、おさるAIマーケ講座（1,100名）講師、2025年UTAGEアワード「ベスト・バックオフィス構築賞」。

## 2. 章別要点

### 第1章｜AI時代でも選ばれる人の共通点（発注側の本音）

**経営者3人へのインタビュー要約**
- 永世さん（複数コミュニティ運営）: 「またお願いします」と言って二度と頼まないことは普通にある。人探しが一番面倒なので、安心して任せられるなら探し直したくない。
- レオさん（UTAGEプロモーション）: 毎回「次どうしますか」が来ると「自分でやった方が早い」になる。安心して任せられる人は目的と優先順位を理解して先に動く。脳のリソースが軽くなる。
- ベイさん（確定申告代行・ECコンサル）: 時給の範囲内でしか動かない人が多い。継続している人は相手の事業に役立ちそうなAI活用事例をサッと共有した。「自分の作業しか見ていないわけじゃない」が伝わった。

**共通点:** 「この人と仕事をしたら自分の負担が減って事業が前に進むか」。見ているのは、判断を何回戻すか／どこまで説明が必要か／途中で不安にならないか／問題時に一緒に解決できるか／目的まで見ているか。

**「次はない」を作る5パターン**
1. 頼まれた作業だけ見て目的を見ない
2. 伝え方で相手の仕事を増やす（「で、私は何を決めればいいの？」が残る）
3. ミスの後が「気をつけます」で終わる → 仕組みで再発防止を見せる
4. 感情の波で連絡・仕事が不安定 → 落ちても回せる形（「確認中、○日までに返信」の一言）
5. 自分の担当だけ見て全体を見ない（次の人が探し直さずに進めるか）

**愛され力を作る3つのマインド:** ①自分への投資を惜しまない ②「納品した」で終わらず相手がどうなったかを見る ③目先の損得だけで決めない（5〜10分のことは返す、大きな仕事は仕事として受ける）。

**比喩:** ラーメン屋。味＝スキル、接客・予約のしやすさ・居心地＝クライアントワーク力。「普通においしい」だけでは足りず「また行きたい」が要る。家事代行が頼まれてない靴をそっと揃える＝小さなプラス1。

### 第2章｜バズらなくても仕事につながるSNS戦略

- SNSは「バズる場所」ではなく「会う前に信用を確認されるインフラ」。紹介された時・名刺交換後・名前を見た時に必ず見られる。
- 毎日投稿・バズ狙い・何でも屋は辞めてよい。目指すのは「何を頼める人か」「どんな価値観で仕事する人か」が伝わっている状態。
- **プロフィールの型:** 「私は〇〇な方を、△△を使ってサポートしています。特に□□が得意です」。「寄り添います」「何でもお任せ」はNG（頼む場面が浮かばない）。
- **プロフィール最低限5つ:** 何をしている／誰のどんな困りごとを助ける／実績・経験／価値観／依頼窓口（窓口の書き忘れが多い）。
- **名前:** 実名不要だが、口に出して呼びやすい／覚えやすい／検索しやすい／第三者が紹介しやすい。
- **アイコン・色:** 「誰と仲良くなりたいか」の目印。著者はアニメ系アイコン×青で、サブカル・ゲーム好きの経営者と繋がる戦略。
- **投稿:** 「やったこと」より「なぜそうするか」。実績ゼロでも学び・工夫・得意・助けたい人・意識していることは発信できる。
- **「ママだけど」→「ママだからこそ」:** 家庭を言い訳として見せると弱点、価値観として見せると武器。
- **透明性:** AIで有益情報は書ける時代。残るのは一次情報と「あなた」そのもの。文章＜写真＜動画・声の順に人となりが伝わる。
- **認知拡大:** 講座・コミュニティで得た学びを発信者本人をメンションして投稿（巨人の肩）。ただし「代弁」であること。八方美人は一瞬でバレる。
- **同業に気を使いすぎない:** 発信の軸は「誰に届けたいか」。同業向けに丸くすると誰にも刺さらない。
- **フォロー相手もブランド:** 価値観が合う人／リアルで会った人のみ。
- **タイムラインの仕込み:** 会う前に相手に刺さる投稿をリポストで上げ直す。相手の趣味に合わせた投稿も混ぜる。Xブックマークのフォルダ分け（有料）で「経営者向け」「ワーカー向け」を整理。
- **実績の見せ方:** 実績は一人では作れない。相手の名前を出した瞬間、相手の信用も預かる。肩書きは借りられても信頼は借りられない。
- **UTAGEアワード事例:** 売上実績ではなく「バックオフィス効率化」「事業者にもアフターファイブを」で勝てる土俵を選んだ。

### 第3章｜売り込まずに仕事が生まれるコミュニティ・オフ会

- 著者はクラウドソーシング・営業DMを6年間ゼロ。名刺も持たない。継続と紹介だけ。理由は「必要になった時に思い出される場所を先に取っていた」から。
- オフ会は仕事を「取る」場所ではなく、信頼と記憶を「残す」場所。売り込む人は浮く。

**参加前**
1. 誰がいるか軽く調べる（主催者・運営責任者・講師・受付・初参加者、を「役割」で把握）
2. 「何の人」として名乗るか一言を決める
3. その場にありそうな困りごとの仮説を1つ持つ
4〜6. 誰に何を聞くか／誰と何を相談するか／その日に何を決めたいか
- 面識ある相手が来るなら事前に一本連絡（相談内容を箇条書きで）

**当日**
- 主催者だけを追いかけない（一番競争率の高い行列）。場を支える人を見る。媚びは見抜かれる。
- 場の目的を見て、できることをやる（一人でいる人に声をかける／忙しそうな人の負担を減らす）。
- 質問の仕方も見られている。丸投げではなく「〇〇を試して△△で止まっている。こう考えたが合っているか」。
- **Wi-Fiケース:** 案内を写真で送る（親切）→ IDとパスワードを別メッセージでテキスト送信（もう一歩先。全員のコピペ手間を先に引き受ける）。

**実例3つ**
- 受付を頼まれ、頼まれてないのに名簿をあいうえお順・決済チェック欄・紙印刷・複数部・蛍光ペン持参 → 「秘書やってるんですか？」→ 打ち上げ同席 → 人脈が一気に広がった。
- 作業会で隣の人のUTAGE設定を手伝う → 本人からも、見ていた別の経営者からも、各10万円超の仕事。
- オフ会でAIを使ってスライドを作っている姿をおさる氏が見て、1,000名超のAI講座の講師に。運は掴める場所に立っていた人が掴む（『ブルーロック』の引用）。

**参加後**
- お礼は24時間以内、「誰だったか・何を話したか・次に何をするか」入り。
- 「試してみます」「資料送ります」は必ず回収して連絡。
- 「また今度」はその場で日程に変える（「で、いつにします？」）。

**横のつながり**
- 同業だけで閉じない。別職種は「広げてくれる人」。「〇〇できる人知らない？」で名前が出るか。
- 誰といるかで自分の「当たり前」の基準が変わる。お疲れさま会だけでは仕事は増えない。

**オフ会時短術:** 時間がない人ほど、月一の場で相談・日程・依頼をまとめて進める方が早い。このBrain自体、熱海合宿で決め、オフ会で関係者と直接詰めて1か月で完成した。

### 第4章｜実務で信頼を積み上げる10ステップ

| # | ステップ | 要点 |
|---|---|---|
| 1 | 日程調整・Zoom案内 | 候補はこちらから出す。曜日入り・24時間表記。Zoomリンクは早めに、送るタイミングも伝える。 |
| 2 | 初回打合せ | 表情が見える・声が聞こえる・誰か分かる。表示名「iPhone」NG。背景は人柄を伝える会話のきっかけにもなる（TPO）。流れ: 機材確認→背景・服装→短いアイスブレイク→目的と終了時刻→ヒアリング。 |

| 5 | 開始 | 「よろしくお願いします」だけで始めない。目的・範囲・初稿日・確認日・素材・連絡場所を一通で残す。ツールは2段階認証。 |

| 8 | 修正 | 回数で責めず「最初の条件」と比べる。範囲を超える時だけ、当初条件・変わった点・追加費用・新納期を事実で並べる。 |
| 9 | 請求 | 宛名・住所・登録番号は公開情報から確認してから聞く。本文にも金額・期限・業務内容。催促は責めず事実だけ＋請求書再添付。 |
| 10 | 入金確認・次の一言 | 「ご入金確認しました」＋相談しやすい余白（「次回は〇〇をチェックリスト化するとスムーズ」）。終了後は権限・データ・ログイン情報を締める。 |

**原則:** 親切をテンプレート化する。気合いの親切は続かない。

### 第5章｜少ない往復で信頼が伝わるテキストコミュニケーション術

- 仕事のやりやすさは9割テキストで決まる。著者は最大8案件同時、10時間睡眠、通知OFF。理由はラリーを減らす「型」。
- **根っこ:** 返信とは文章を送ることではなく安心を送ること。
- **読む前の整え:** アイコン・表示名・プロフィール欄で「誰からの連絡か」を迷わせない。一文ごとに改行、意味の区切りで一行空け。
- **トーン:** 正解はクライアントごとに違う。新しい現場は最初1〜2週間を観察期間（文体・挨拶・絵文字量・報告の長さ・緊急連絡方法）。信頼されているスタッフのやり取りが生きた見本。相手が「こうしてほしい」と言ったら自分の作法より優先（「あやねえと呼んで」を頑なに拒んだ人の例）。礼儀は最上級に、意見はまっすぐに。
- **用件ラベル:** 【ご確認】【ご報告】【ご相談】【ご提案】【対応不要】。特に【対応不要】が効く。
- **7つの型:** 用語定義参照。
- **送信前5秒チェック:** 冒頭で何の連絡か分かる／してほしいことが分かる／期限・理由がある／返信不要なら書いた／スタンプか一言で返せる形か。
- **ツール別:** LINE（有料プランでビジネス用サブプロフィール、アルバム共有）／Chatwork（TO・引用、タスク機能、概要欄にURL、1メッセージ1情報）／Slack（スレッド、@here乱用しない）／メール（件名で用件、TO/CC/BCC、引用返信）。同じ依頼を複数ツールに重複送信しない。案件ごとに主連絡場所を一本化。
- **テキストが不向きな時:** 写真・スクショ（矢印・囲み）／音声・動画（感情・操作手順。何についてか・何分か・どこを見るか・返信要否・結論テキストを添える）／通話（緊急・往復が続く・認識ズレ）。通話で決まったことは必ずテキストに戻す。
- **辞書登録:** 相手の名前・会社名・商品名・署名・定型文（子音2文字で登録: md/zm/sk/nh）。パスワード・APIキー・個人情報・機密・カード情報は登録しない（クラウド同期される）。

### 第6章｜長く付き合えるクライアントの選び方

- 仕事を選ぶのは贅沢ではなく、良い仕事をするために余力を守ること。一社依存は「切られたくない」で境界線が崩れる。
- **面談前に決める5条件:** ①稼働できる曜日・時間 ②夜間・休日対応の可否 ③最低報酬ライン ④できる業務・できない業務 ⑤絶対に譲れないこと。面談中に全部「大丈夫です」と答えたものは後で自分の首を絞める。
- **見る3つ:** ①支払いとお金の扱い ②外注をどう扱っているか（安く使える作業員か／役割増で報酬・裁量も見直すか／改善を価値として受け取るか） ③コミュニケーションと敬意（評価基準が日によって変わらないか／前任者の悪口）。
- 「契約書がない＝即アウト」ではない。問題は条件を明確にすること自体を嫌がること。「会社の一員として考えて」で責任だけ求めるのは搾取。
- **事業フェーズ:** 一人社長立上げ期（全体が見える、境界線が溶けやすい）／成長期（業務改善・進行管理・仕組み化が活きる）／組織化企業（正確・安定）／インフルエンサー事業（業務量の波が大きい、マーケ必須、影響力も得られる）。
- **違和感→まず条件調整:** 返信タイミング／業務範囲の整理／緊急対応を分ける、を文面で相談。調整に応じるか、不機嫌になるかが判断材料。
- **手放す:** 責めずに「今の条件では続けられない」。終了日・残タスク・引き継ぎ・データ・権限・最終請求を整える。手放した後に同じ条件の案件を取らない。
- **辞め方までがクライアントワーク:** 去り際で信頼が決まる。著者も適任者に役割を渡し、生まれた余白で講座・コンテンツ・講師業に進んだ。

### 第7章｜信頼を継続・紹介・収入アップ・セカンドキャリアに変える

- **継続:** 契約終了時にお願いするものではなく、仕事の途中で決まっていく。「すぐ隣の仕事」の種を置く。納品時に「何が前に進んだか」を添える。
- **見えない仕事を見える化:** 業務報告書5項目。因果不明の売上を自分の手柄にしない。
- **単価アップ:** 「お願い」ではなく「すり合わせ」。契約開始時と現在の担当範囲を並べて役割ベースで相談。上げられないなら範囲・稼働・別料金・次回見直し時期で調整。
- **時給 vs 固定:** 業務量が読めない・内容が変わる・試用期間は時給。毎月の業務が固定・範囲を定義できる・役割で価値を説明できるなら固定。
- **実話:** 月5万の運営スタッフ → 写真・X運用・動画編集を小さく提案 → 1年で月15万。交渉ではなく役割が広がって報酬が付いてきた形。ただし責任だけ増えるなら止まる。
- **紹介:** 「紹介してください」より先に「紹介しやすい人」でいる。紹介されたら即お礼、結果を紹介者に返す。人をつなぐこと自体が収入になることもあるが、報酬が絡むなら関係者に見える形で。
- **セカンドキャリア:** ディレクター／マネジメント／講師／研修／コンサル／講座／コンテンツ。「それどうやってるんですか」と何度も聞かれたら、そこに知りたい人がいる。現場の知見はAIに代替されない。教える側が最終ゴールではない。

### 第8章｜3児ママでも複数案件が回るタスク管理

- 仕事ができる人は全部覚えている人ではなく、覚えなくても漏れない場所に置いている人。頭は覚えるためではなく考えるために使う。
- **ツール:** Googleカレンダー＋紙ノートのみ。Notion・有料アプリ・朝活・ジャーナリングはやらない。
- **1日:** 6:00起床 → 9:00〜12:00コアタイム（重い仕事、通知OFF）→ 昼前後に返信まとめ → 午後は中断前提の軽い仕事・打合せ → 夕方以降は家族時間＋ながら仕事 → 23〜24時に寝る前ルーティン。
- **カレンダー:** 仕事・家庭・休みを全部同じ画面で重ねる。色は「モード」で4色（青=自分の作業／黄=人が絡む予定／ピンク=家族／緑=自分のための時間）。締切だけでなく「作業する時間」を置く（予定表にないタスクは願望）。
- **休み・余白を先に置く:** 空白は仕事から「空いている時間」に見える。予定は7〜8割で組む。クライアント締切の前日に自分の締切。水曜午後・金曜午後を余白に。
- **家事育児:** 「全部自分でやる」を捨てる。家事代行・家族・義実家・サービス。忙しい時期は終了日を決める。申し訳なさそうに仕事しない（「30分だけ頑張るね」と宣言）。
- **元に戻す時間:** 毎日（引き継ぎ書・開始前確認・終了時更新）／週初め（締切・打合せ・素材待ち・返信待ち・自分が止めている仕事・請求）／週末。「自分が止めている仕事」を見にいく。

### おわりに

- 長く選ばれる人＝目の前の相手と仕事を雑に扱わない人。信頼は派手な一発ではなく小さな安心の積み重ね。
- 著者は「自分はすごい」より「今の自分にできることで相手の仕事を少し前に進められないか」を壁に貼って忘れないようにしている。

## 5. 自分（MAYU）への適用メモ

- **100チャレ／Claudecord の顧客対応:** 第4章10ステップと第5章の型をそのまま「納品物＋どこを見るか＋確認期限」の形に載せる。Claudecord の月額顧客への月次連絡は「業務報告書5項目」を流用できる。
- **SaaS販売の前段:** 第2章の「勝てる土俵」＝整骨院×AI自動化の一次情報。売上実績ではなく「現場で回している人」のポジションで発信する。
- **発注側の視点:** 100チャレの依頼者はこちらが「受注側」。「判断を戻す回数」「【対応不要】ラベル」「A案/B案で返せる形」を守る。
- **GAS/LINE 化の候補:** 業務報告書テンプレをスプレッドシート＋GAS で月次自動生成／「受領＋返信予定」の定型文を LINE 公式の自動応答へ／10ステップ文面を辞書登録（子音2文字ルール）。
- **クライアント選定:** 5条件（稼働時間・夜間対応・最低報酬・できないこと・譲れないこと）を Claudecord 契約前チェックとして明文化しておく。
