# フルテロップの作り方（校閲の手順）

`captions` が出す字幕は**初稿**。初稿のまま書き出さない。全文を1枚ずつ読み直し、この手順で作り直してから `--captions` に渡す。手本は同じフォルダの `caption-sample.json`。

## 形の基準（手本の実測値）

| 項目 | 基準 |
|---|---|
| 行数 | **1行のみ**。長いときは2枚に分ける。改行しない |
| 字数 | 1枚8〜17字が中心。平均13字前後、最大23字 |
| 句読点 | 付けない。「、」「。」は消す。息継ぎの間は半角スペース1つ（例：「6000回 1日ぐらいで回るなら」） |
| 読む速さ | 1秒あたり12字を超えない |
| 表示時間 | 発話の最初の語の頭から、最後の語の終わりまで。次の字幕までの0.3〜4秒の隙間は、前の字幕を延ばして埋める |

利用者が句読点ありや2行を指定したときは、その指定を優先する。

## 1枚＝1つの意味で切る

- 切ってよい位置の強さは、**文末 ＞ 接続助詞（〜けど・〜ので・〜から・〜て）の後 ＞ 格助詞（〜を・〜に・〜が）の後**。
- 言いかけで終わらせない。「この」「その」「ちょっと」「て」「で」「と」で1枚を終えない。
- 語の途中で切らない。漢字と送り仮名（分｜かった、安｜く）、カタカナ語、英数字の途中で割らない。
- 次の字で1枚を始めない：ん／っ／ー／ゃゅょ／ら行の活用（られ・れる等）／よ／ね／です／ます。
- 1枚に2つの文を入れない。

## 削る（音声は触らない。字幕の文字だけ）

- **フィラー**：えー／えーと／あの／あのー／その（指示でない）／まあ／なんか／ちょっと／やっぱ／やっぱり／なんていうか／っていうか／いや（文頭）／はい（相づち）／そうそう／よっしゃ／じゃあ（話の区切りだけのもの）
- **数量の後の「ぐらい」「とか」**。ただし「どのぐらい」「これぐらい」の指示・疑問は残す。「なんとか（somehow）」の「とか」は残す。
- **言い直し**：最終形だけ残す（「これが、これはですね」→「これは」）。
- **文頭だけの「で」「だから」**：話の区切りだけで意味がないとき。

残すもの：「もう」などの話者の口癖、一人称、方言・口語（やばい・めっちゃ）、留保（〜かもしれない・たぶん）。**言い換え・要約はしない。** 詰めるのは削る語だけで、意味や順序を変えない。

話し言葉のゆれは読みやすく直してよい：やっとる→やってる、入っておると→入ってると。

## 反復とカット境界

同じ語を2回言った箇所は、同じ字幕を2枚点滅させず、1枚で両方の発話をまたいで出す。保持区間を越えて延ばさない。

カットで音が残らない発話の字幕は残さない。保持区間の頭に前の話の字幕を出さない。校正後にカットを変えた場合は、残った単語列へ時刻を合わせ直し、区間の頭と末尾の原音を確認する。

## 文脈で誤変換を直す（辞書では直せないもの）

`references/vocabulary.json`（と利用者の `vocabulary.local.json`）の置換は既知の語だけを直す。**置換が0件でも誤りがないとは判断しない。** 話の中身から判断して直す。

| 認識結果 | 正しくは | 手がかり |
|---|---|---|
| SLS | SNS | マーケ・発信・フォロワーの話 |
| 帽子込み | 募集 | 面談・枠の話 |
| ネギメ | 値決め | 価格設定の話 |
| 紙 | 神 | 「神レベル」の意味 |
| プレミア | Premiere | 動画編集ソフトの話（有料プランの「プレミアム」とは別） |
| 身だし並み | 身だしなみ | 一般語の誤分割 |
| 際じゃあ | 実際じゃあ | 語頭の1字欠け。原音を聞き直す |

- 人名・社名・商品名が怪しいときは、話の流れと素材の説明文から判断する。確信がないものは直さずに一覧にして利用者に聞く。
- 1字欠け・語の脱落（クラウドフア等）は、前後の単語時刻の原音を確認して補う。

## 仕上げの確認

1. `ytedit.py qc` の字幕検品が FAIL 0（1行・字数・読む速さ・句読点・行頭NG・言いかけ終わり・フィラー残り・未補正語）。
2. 直した語と、判断に迷って残した語を一覧にして報告する。
3. 字幕全文を通し読みしていない場合は、その事実を記録する。
