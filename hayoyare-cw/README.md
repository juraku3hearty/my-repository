# 📢 ハヨヤレ Chatwork版 — マイチャットに住み着く関西弁おばちゃん

Slack版と同じ機能のChatwork版。上司からの連絡を全自動で拾い、AIが「何を・いつまでに」を読み取って登録、
期限が近づくとマイチャットで詰めてくる（😗→😤→💢→👹）。

## Slack版との違い

- **導入がさらに簡単**：アプリ作成・OAuth不要。ChatworkのAPIトークン1本で動く
- おばちゃんの住処は**マイチャット**（自分専用ルーム。他の誰にも見えない）
- コマンド体系は同一：`やった` `ちゃう` `消して 2` `直して 2 期限は金曜15時` `リスト` `設定` `ヘルプ`

## セットアップ（10分）

1. Chatwork画面右上の自分のアイコン → **サービス連携** →（左メニュー）**APIトークン** → パスワードを入れてトークンをコピー
   ※組織契約の場合、管理者がAPI利用を許可していないと表示されないことがある → 管理者に「APIトークンの利用許可」を依頼
2. GASプロジェクト新規作成 →「ハヨヤレCW」→ この7ファイルを貼り付け
3. スクリプトプロパティ:
   - `CHATWORK_API_TOKEN` = 1のトークン
   - `GEMINI_API_KEY` = Google AI Studio のキー（専用プロジェクトで作ると無料枠が独立する）
4. `initialize()` 実行（権限承認）→ **マイチャットに着任挨拶**が届いたら本体OK
5. `listMyRooms()` 実行 → ログのルーム一覧から監視したいルームIDを選んで
   スクリプトプロパティ `WATCH_ROOMS` にカンマ区切りで設定
6. （任意）`BOSS_ACCOUNT_IDS` に上司のアカウントIDを設定。空なら自分以外の全員が対象
7. もう一回 `initialize()` → 完成

動作テスト: `testNag()` でマイチャットに催促が届く。
