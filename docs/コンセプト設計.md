## 1. 確定事項

### コンセプト（着地点・1つ・固定）

```
AIで仕事を受けたい人へ｜新しいアプリを作らず、LINEの中で業務を自動化する。
非エンジニアが調べ方と聞き方だけで実案件を作ってきた方法を発信します
```

- **軸（思想）**：アプリを作らない／相手が普段使っている道具の中で完結させる
- **主戦場（見せる場所）**：LINE
- **再現性の根拠**：調べ方と聞き方（＝切り口を変える力）
- **運用形態**：別人格（本業・実名と紐づけない）

### 3層構造（順序を崩さない）

```
表（見せる）     LINEで動く自動化           ← 誰でも分かる／興味を持たせる
中（証明）       GAS・スプレッドシート       ← 作れる証明
核（なぜできた） 切り口を変えて探す・聞く力   ← 再現性・唯一の差別化
```

| 層 | 出る場所 |
|---|---|
| 表：LINE | コンセプト／プロフィール1行目／タイトル／サムネ |
| 中：GAS | 本文の後半／特典の中身 |
| 核：調べ方と聞き方 | プロフィール3要素目／記事の中盤以降／特典の設計思想 |

**順序の理由**
- 別人格は実名の信頼が使えないため、**信頼を作る手段は成果物しかない**。よってGASは隠さず後半で必ず出す
- 核を看板にすると成果物が消え、「プロンプトの書き方」という激戦区に入る。かつ匿名で抽象的な話は信用されない
- 核がないと「非エンジニアが作れました」は再現性のない自慢で終わる。核があると読者が真似できるノウハウになる

### 却下した案と理由

| 案 | 却下理由 |
|---|---|
| AI×業務効率化 | 成果物が見えない。「AI」と同じ広さ |
| AI×副業で稼ぐ | 匿名 × 「稼げます」は最も信用されない組み合わせ。かつ実践在庫が全部使えなくなる |
| AI×GAS（GASを表に） | 読者がGASという言葉を知らない。入り口として機能しない |
| AI×整骨院の業務自動化 | 絞りすぎ。他2件の実績が軸から外れる |

## 2. 実践在庫（一次情報）

匿名運用のため、顧客の固有名詞・業種は出さない。抽象化した表現を併記。

| 案件 | 届けた場所 | 新しく覚えさせたもの | 匿名で書くときの表現 |
|---|---|---|---|
| 献立AI（LINE Bot × GAS × Gemini） | **LINE** | なし | 「LINEで送ると献立と買い物リストが返ってくる仕組み」 |
| タイムカードOCR → 既存Excelへ転記 | **相手が既に使っていたExcel** | なし | 「画像から勤務時間を読み取り、相手が既に使っていたExcelにそのまま転記」 |
| 動画の自動アップロード | **Webフォーム** | なし | 「フォームから投げると自動でアップロードされる仕組み」 |
| AI環境の構築と月額保守 | **顧客のDiscord** | なし | 「AI環境の構築と保守を月額6,600円で複数社に提供」 |

### 最強の一枚
**タイムカードOCR → 既存Excel転記**。裁判所提出用のExcelフォーマットを1ミリも変えず、そこに流し込んだ。
新しい画面を作れば実装は楽なのに作らなかった＝**思想が先にある証拠**。そのまま記事になる。

### 人からよく相談されること（＝需要の外部証拠）

他人が繰り返し聞いてくること。自己申告の実績と違い、**需要の裏付けがある唯一の項目**。

- 「どうやって調べるの？」
- 「どうやってやってるの？」
- （AI以前から）「どこで売ってるの？」「なんで見つけられるの？」

**内容**：検索で打ち込む語の選び方が独特で、みんなが見つけられないものを切り口を変えて引っかけるのが得意。

**AI時代における意味**：検索の切り口を変える力 ＝ プロンプトの切り口を変える力。**対象が変わっただけで能力は同一**。
AI界の発信の大半は「プロンプト集」＝答えを渡す形で、切り口の作り方を渡す発信はほぼない → 被らない。

**読者との接続**：「AIで稼ぎたいけど作れない」人が詰まっているのは技術ではなく、
詰まったときに何を聞けばいいか分からないところ。
「スキルがないから作れない」→ **「調べ方と聞き方で埋まる」**（独学・非エンジニアで4件納品という実証つき）。

### 月額化の理屈（稼ぎたい読者との接続点）
```
LINEで作る → 相手の環境で動き続ける → 運用が発生する → 月額保守になる
```
アプリを納品すると終わるが、LINEは動き続けるので保守が必要になる。
単発→月額の理屈が**技術選択から自動で出てくる**。実例が月6,600円の継続課金。

## 3. 入り口の在庫（複数・自由・広い）

コンセプトは固定したまま、話の始め方は変えていい（講座 2-6）。

### ① 稼ぐ側の悩み（Xの読者の大半）
- AI案件が単発で終わって、毎月ゼロから営業している
- 単価が上がらない
- アプリが作れないから案件を受けられない

### ② 作業の悩み（実務者・事業者）
- 毎月同じ転記作業をしている
- 紙や画像から数字を手で打ち込んでいる
- スプレッドシートの更新が終わらない

### ③ AI活用の悩み（ツールは触っているが成果が出ない層）
- ChatGPTを使っているけど仕事につながらない
- ツールを増やしたのに結局手作業が残っている

### 入り口の判定基準

> **その記事の後半に、自分の実践か作った仕組みが出てくるか。**

出てこないなら入り口ではなく**脱線**。

| | 判定 |
|---|---|
| 「時間管理術」から入って、最後に作った仕組みを見せる | ◯ 入り口 |
| 「時間管理術」の話で終わる | ✗ 脱線 |
| 「AI副業の稼ぎ方」から入って、月額化の設計に着地 | ◯ 入り口 |
| 「AI副業の稼ぎ方」一般論で終わる | ✗ 脱線（差別化ゼロの激戦区） |

## 4. 記事の展開パターン（設計済み）

### 例A：稼ぐ側の入り口 × 月額化への着地（実績・思想型）
```
入り口   「AI案件、納品して終わりで毎月ゼロから営業してませんか」
  ↓
共感     単発だと毎月リセットされる
  ↓
一次情報 作った仕組みを納品して終わりにせず、保守として月額で受けた
  ↓
なぜ    LINEで作ると相手の環境に残る → 運用が続く → 保守が必要になる
  ↓
着地    だから最初からLINEの中で作る          ← コンセプト
  ↓
案内    自動化の設計チェックリスト（特典）
```

### 例B：作業の悩みの入り口 × 作れる証明への着地（ガイド型）
```
入り口   「毎月タイムカードを手で集計してませんか」
  ↓
一次情報 勤務時間の集計を自動化した案件（業種はぼかす）
  ↓
仕組み   画像 → OCR → 既にあるExcelに自動転記。手入力ゼロ。新しい画面は作らない
  ↓
着地    普段使っている道具の中でここまでできる  ← コンセプト
  ↓
案内    テンプレ一式（特典）
```

### 例C：核（切り口）を主題にした記事（診断・理論型）
```
入り口   「エラーが出た瞬間に手が止まりませんか」
  ↓
一般認識 スキルがないから作れない、と思われている
  ↓
指摘    止まる原因は技術ではなく、何を聞けばいいか分からないこと
  ↓
一次情報 非エンジニアで4件作れた理由は、調べ方と聞き方だけ
  ↓
着地    切り口を変えて聞けば埋まる            ← 核
  ↓
案内    質問の切り口テンプレ（特典）
```

### 記事テーマのストック
- 「エラーが出たときAIに何を渡すか。画面をそのまま貼るだけで9割解決する」
- 「探せる人と探せない人の差は、知識じゃなくて打ち込む語の選び方」
- 「作り方が分からないものを作る手順。完成形から逆に聞いていく」
- 「AI案件を単発で終わらせない。LINEで作ると保守が発生する」（＝却下した案2の中身）

## 5. 特典の第一候補（第6章の掛け合わせ）

### 第一候補：**「詰まったときにAIへ投げる質問の切り口テンプレ」**

| 理由 | |
|---|---|
| 差別化 | プロンプト集（＝答えを渡す）ではなく**切り口を渡す**。AI界でほぼ被らない |
| 汎用性 | どんな商品と掛け合わせても成立する → 紹介商品が変わっても使い回せる |
| 需要の裏付け | 「どうやって調べるの」は実際に繰り返し相談されている内容 |
| 読者の障壁に直撃 | 作れない原因は技術ではなく「何を聞けばいいか分からない」ところ |

### 第二候補：**「公式LINEの応答メッセージで特典を自動配布する仕組み（LINE × GASテンプレ一式）」**

| 理由 | |
|---|---|
| 需要 | Brainアフィをやる全員が第7章で必要になる |
| 自分の強み | 普段やっていること。他の受講者は初めてで苦戦する箇所 |
| 軸との一致 | LINE主戦場・GASが中身 → 3層構造どおり |
| 副産物 | 講座の第7章を進める作業が、そのまま記事1本と特典1つになる |

※特典の価値は中層（GAS）と核（切り口）で出す。「LINEの使い方」だけだと価値が薄い。

## 6. 別人格の運用ルール（第7章に効く）

1. 公式LINE・オープンチャットは、この人格専用に**新規で作る**（本業・既存と混ぜない）
2. アカウント名と画像を X / LINE / オープンチャット で統一
3. 立場の書き方：実名を出さず「店舗の現場で働きながら、自分の業務から自動化してきた」で成立する
4. **配布用Googleドキュメントは別人格用のGoogleアカウントで作る**（アカウント名が表示される場合があるため）
5. 顧客名・連絡先・購入画面のスクショは、記事・AIへの入力の両方に入れない

### 入り口での注意
LINE発信者の大半は「LINE公式アカウント × マーケ集客」（リスト取り・ステップ配信）。
自分がやるのは**業務そのものをLINEで動かす**（社内・現場用途）ので、最初の1行で区別を明示する。

```
✗ 「LINEを最大限使う方法」
◯ 「集客じゃなくて、業務そのものをLINEの中で終わらせる」
```
