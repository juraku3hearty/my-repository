# 交通事故 問診票ジェネレーター セットアップ手順

院ごとに「院名入りのWeb問診票」を発行する仕組みです。
PDFを配らず、**その院の名前が入った状態でしか存在しない**形にしてあります。

---

## 全体の流れ

```
LINE友だち追加
　↓ 専用リンクが自動で届く
院名を登録（30秒）
　↓
① 患者さんに見せるWeb問診票URL（QR付き）
② 院名入りの印刷用シート
③ 届いた問診を見る管理画面
　↓ 患者が記入すると
院長のLINEに「確認が必要な項目」が届く
```

---

| `03_Clinic.js` | 院マスタの登録・取得 |
| `04_Intake.js` | 患者の問診回答の保存 |

## セットアップ

### 1. コードを反映する

```bash
clasp push
```

### 2. `setup()` を実行する

GASエディタで `setup()` を1回実行します。

- スプレッドシートが新規作成され、`SPREADSHEET_ID` が自動で設定されます
- `院マスタ` `問診回答` `設定` の3シートが作られます

### 3. スクリプトプロパティを設定する

GASエディタ > プロジェクトの設定 > スクリプト プロパティ

| キー | 値 |
|---|---|
| `LINE_CHANNEL_ACCESS_TOKEN` | LINE Developers で発行したアクセストークン |
| `LINE_CHANNEL_SECRET` | 同チャネルシークレット |
| `WEBAPP_URL` | 手順4で取得するデプロイURL |
| `DESK_URL` | 交通事故実務デスクのLP URL（任意） |

**トークンはコードに書かないでください。**

### 4. ウェブアプリとしてデプロイする

デプロイ > 新しいデプロイ > 種類「ウェブアプリ」

| 項目 | 設定 |
|---|---|
| 次のユーザーとして実行 | 自分 |
| アクセスできるユーザー | **全員**（患者が記入するため） |

発行されたURLを `WEBAPP_URL` に設定します。

### 5. LINEのWebhookを設定する

LINE Developers Console > Messaging API設定

- Webhook URL: 手順4のデプロイURL
- Webhookの利用: オン
- 応答メッセージ: オフ

### 6. 動作確認

`createTestClinic()` を実行すると、テスト院が1件作られてログに3つのURLが出ます。
ブラウザで開いて、記入 → 管理画面に出るところまで確認してください。

## URL一覧

| 用途 | URL |
|---|---|
| 院の登録 | `{WEBAPP_URL}?p=reg&t={adminToken}` |
| 管理画面 | `{WEBAPP_URL}?p=admin&t={adminToken}` |
| 患者の記入 | `{WEBAPP_URL}?p=intake&c={publicId}` |
| 印刷用 | `{WEBAPP_URL}?p=print&c={publicId}` |

`adminToken` は院長専用です。`publicId` は患者に見せるIDで、院長用の情報は見えません。

## 設計上の約束（変更しないでください）

### 1. アラートは「確認項目」であって、判断ではない

`05_Alert.js` が出すのは「院長の確認が必要な項目」だけです。
受付がそのまま患者や保険会社に説明できる文言にしないでください。
必ず「院長が確認する」で終わる形にしてあります。

### 2. 印刷用シートに、判断の根拠を書かない

紙の元シートにあった
「法律上【整骨院のみに通院すること】は可能です」
といった説明文は、`ui_print.html` に入れていません。

ここが院のノウハウの中心で、紙で回されると価値がそのまま流出するためです。
印刷用には確認の3問だけを残し、
「通院の進め方については、担当の施術者よりご説明いたします」
で止めてあります。

### 3. 13日というしきい値の意味

`DAYS_THRESHOLD = 13` は法令上の基準ではありません。
**14日でだめだったケースがあり、13日でだめだったケースがない**という
院長の経験から引いた線です。

14日を超えた場合は断る判断ではなく、
**遅れた理由を聞いて記録する**フローに入ります（`遅延理由` 欄）。

### 4. 「病院での案内」欄がある理由

初回の電話で「まず病院に行ってください」と案内すると、
病院で「整骨院には行くな」と言われ、患者が二度と戻らないケースが実際にあります。

この欄で「整骨院には行かないように言われた」が選ばれると、
**最優先のアラート**が出て、院長が直接説明する導線に入ります。
受付で対応させないための設計です。
