# ダンドリ — 確定仕様ブリーフ v2（壁打ち反映済み）

あなたが以前作成した「家族の段取りボード」依頼文をベースに、実運用者の知見で仕様を確定させた。以下を**確定事項（変更不可の前提）**として扱うこと。

## 製品概要
- **名称：ダンドリ**（段取り＋鳥のダブルミーニング。キャラクター＝よく喋る世話焼きの鳥「ダンドリ」）
- コンセプト：**詳細は自分だけ、段取りは家族だけ。** 家族の共有カレンダーではなく「家を回す段取りボード」
- 技術スタック確定：Next.js + Supabase + Vercel + LINE（Messaging API / LIFF）。運用者に同スタックの本番実績あり

## 設計原則（3本柱・最優先）
1. **家族は入力しない。返事するだけ。** 家族アプリが死ぬ原因は入力しない家族。ダンドリの方からLINEに聞きに来て、ボタン1タップで完了。登録する人は家庭に1人でいい
2. **平和な日は、鳥は黙る。** 毎日全員に「夕飯いる？」と聞くのは間違い（基本家で食べる人・毎日聞かれるのが嫌な年頃がいる）。各自が**曜日別のデフォルト**（夕飯いる/いらん・帰宅目安・弁当）を持ち、ダンドリが扱うのは**例外と未確定だけ**。「今日いらん」は本人がワンタップ申告。初期設定ウィザードでデフォルトを**最初に必ず**登録させる
3. **リマインドは、お母さんに集めない。** 通知は担当者本人へ直接（ジャージ→長男、迎え→父）。担当未定のものだけ全員募集→最初に【引き受ける】を押した人で確定。母に届くのは母担当分と家族未決分のみ。このアプリの存在意義は「母が家族の予定係から降りられること」

## 配布・接続アーキテクチャ（確定）
- **中央集権型：運営の「ダンドリ」LINE公式アカウント1個に全家庭が接続。** 一般家庭はLINEチャネルの自作など絶対にできないため、利用者の作業は友だち追加/グループ招待のみ。「セットアップ」という概念を消す
- **二層通知（グループ招待方式）：** ダンドリ（Bot）を家族のLINEグループに招待する
  - グループ層＝募集「17時の迎え、誰か行ける？」・全員連絡「明日は遠足、弁当やで」・金曜の棚卸し
  - 1対1層＝個人の担当リマインド・個人予定の登録・プライベートな確認
- **紐付けフロー：** 母がダンドリをグループに招待 → ダンドリ「みんな、自分の名前タップしてや」→ 各自1タップで LINEユーザー⇔家族メンバーの紐付け完了（グループ在籍＝家族の証明）。グループの無い家庭用に招待リンク方式も予備で用意
- **メンバー3タイプ：** ①LINE接続（自分宛のことだけ届く）②プロフィールのみ（LINE無しの子等。通知は担当親へ）③通知オフ（年頃の子。開いた時だけ応答）

## LINE課金の実測事実（運用者の実データ。この前提で設計すること）
- **Push（こちらから送る）＝受信人数分カウント。** 実測：30人グループへ5回送信→150通消費（無料枠200が即枯渇）
- **Reply（ユーザーの操作への応答）＝無料・無制限。** 実測：問い合わせ応答Botを無料枠内で長期運用
- 帰結：大人数グループへのPushは構造的に不成立。**家庭（4〜5人）だから成立する**ビジネスである
- 有料家庭の想定通数：個人リマインド40〜60通＋グループ発言10回×4人 ≒ **月100通前後＝原価100〜150円/家庭**
- 規模拡大時のレバー：グループまとめ便（1日1回に集約）／重要度の低い通知はボード掲載のみに格下げ（開けば見える＝無料）

## 料金モデル（フリーミアム・確定）
- **無料版＝reply型：** ボード・定型入力・個人予定表・会話クエリが使える。ただし**ダンドリは自分から喋らない**（開いた時・聞かれた時だけ応答＝原価ほぼゼロ）。OCRは体験1回
- **有料版（月500円/家庭 or 年3,000円）：** ①毎朝ダンドリが自分から聞きに来る（**「鳥が自分からさえずるのは有料」が課金の柵**）②行事プリントOCR無制限 ③通知の回数・時間帯カスタム ④Googleカレンダー連携（v2、**有料限定確定**）
- 無料版を堂々と使える完成品にするのは意図的（拡散の燃料。原価がかからないから可能）

## 💬 会話クエリ（無料版の主役機能）
「今日の予定は？」「明日って弁当いる？」「今週の送迎は？」と**LINEで聞けば、その家族のボードを組み立てて返す**。動的な内容でもLINE課金上はreply＝無料・無制限。AI（Gemini）を挟むので聞き方は自由な日本語でよい。
→ 無料版は「聞けば何でも答える家族秘書」。有料版との差は「聞かなくても向こうから来るか」だけ、という明快な柵になる。

## 🌟 キラー機能：行事カレンダーOCR自動入力
学校・園の月間プリント/年間行事表を**写真で送るだけ**→ Gemini Visionが日付・行事・持ち物を構造化抽出（体育→ジャージ、遠足→弁当・水筒の推論込み）→ 準備タスクとして自動登録（前日夜・当日朝リマインド）→ 誤読は「直して」で修正。運用者に同方式のOCR本番実績あり。**競合の共有カレンダーに存在しない差別化機能**

## MVP機能（フェーズ1）
1. 家族グループ作成・子どものアカウント不要プロフィール（LIFF）・初期設定ウィザード（曜日別デフォルト必須入力）
2. 今日・明日・今週の段取りボード（月間カレンダーUIは作らない）。未回答・未定・期限超過を最優先表示
3. 定型入力（夕飯・弁当・送迎・帰宅・家事依頼）＋短文入力
4. **個人予定表**：詳細（タイトル・場所・メモ）は本人だけ。登録時に家族への見せ方（外出/帰宅目安/送迎/夕飯影響）をワンタップ選択＝**1回の入力で個人予定と家族共有が同時に完了**
5. プライバシー分離（家族に見えるのは抽象情報のみ）
6. 行事プリントOCR自動入力
7. 会話クエリ（「今日の予定は？」への動的応答）
8. ダンドリ通知（担当者直行ルーティング・二層設計）
9. 状態変更（完了/引き受け/不要/あとで）

**やらないこと：** 位置追跡・交友関係記録・家計管理・月間カレンダーUI・カレンダー連携（v1）・Outlook

## 検証計画
最初の顧客＝運営者自身の家庭で1ヶ月パイロット（グループ内replyの無料カウント実測を含む）→ 実使用データでMVPを削って磨く → フリーミアムで一般公開
