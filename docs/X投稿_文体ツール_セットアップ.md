# X投稿 文体ツール セットアップ

過去の「業者さんの雛形」と「自分の書き換え」の差分から文体ルールを取り出し、
以後はその文体で投稿案を出すツールです。

**狙いは業者さんの再現ではありません。書き直す工程をなくすことです。**

---

## 前提にしているシートの形

A列にラベルが縦に繰り返し、**B〜H列が1週間分**（1列＝1日＝1投稿）。

```
        B          C      D      E      F      G      H
日付    月         火     水     木     金     土     日
投稿日  2026-10-19 …
投稿文  ← 業者さんの雛形
修正欄  ← 自分の書き換え
（空白行）
日付    ← 次の週のブロック
```

列の位置やラベル名が違っても、`X_設定` シートで変更できます。
1行目が見出しの普通の表でも動きます（`レイアウト` を「表（横）」にする）。

---

## ファイル構成

| ファイル | 役割 |
|---|---|
| `10_XConfig.js` | 設定・モデル・シート名 |
| `11_XClaude.js` | Claude API（UrlFetchApp。GASはSDKが使えないので素のHTTP） |
| `12_XMap.js` | シートの読み取り（週ブロック／表の両対応） |
| `13_XExtract.js` | 文体ルールの抽出（バッチ・再開可） |
| `14_XGenerate.js` | 投稿案の生成＋週ブロック形式での書き出し |
| `15_XMenu.js` | スプレッドシートのメニュー |

モデルは **`claude-opus-5-5`**。文体の再現が目的なので、安いモデルには落としていません。

---

## セットアップ

### 1. スクリプトを過去ログのスプレッドシートに入れる

スプレッドシートを開く → 拡張機能 → Apps Script → `10_`〜`15_` のファイルを貼る。

（別プロジェクトで動かす場合は、スクリプトプロパティ `X_SPREADSHEET_ID` に
過去ログのスプレッドシートIDを設定してください）

### 2. APIキーを設定する

プロジェクトの設定 → スクリプト プロパティ

| キー | 値 |
|---|---|
| `ANTHROPIC_API_KEY` | Claude APIキー |

### 3. メニューから順に実行する

シートを開き直すと「**X 文体ツール**」メニューが出ます。

| 手順 | メニュー | 内容 |
|---|---|---|
| ① | 設定シートを作る / 更新する | `X_設定` が作られ、レイアウトと列を自動推測して埋めます |
| ①' | 読み取れるか確認する | 何件読めたかをログに出します。**ここが0件なら設定を直す** |
| ② | 文体を抽出する | 12件ずつ処理。時間切れで止まったら**もう一度押す**と続きから |
| ③ | 今週の投稿案を作る | テーマと本数を聞いて生成 |

---

## ① の前に、`X_設定` で必ず埋めるもの

| 項目 | 内容 |
|---|---|
| 対象シート名 | 過去ログのシート名 |
| レイアウト | `ブロック（縦）` または `表（横）` |
| ▼値の開始列 / ▼値の終了列 | 既定は B と H（1週間7日） |
| **これからのコンセプト** | **ここが空だと生成できません。**内容はここだけから作ります |

`アカウント紹介` `投稿の方向性` `扱わないこと` は任意ですが、
入れるほど生成の精度が上がります。

---

## ② 文体抽出で何を取り出しているか

雛形と実投稿を並べて、AIに差分を読ませます。

| 取り出すもの | 意味 |
|---|---|
| **禁止語** | 業者さんが書いたのに、自分が消した語。**これが一番重要** |
| 採用語 | 雛形になく、自分が足した語 |
| 文の長さ / 改行 / 語尾 / 一人称 | 形の特徴 |
| 冒頭パターン / CTAパターン | 入り方と締め方 |

結果は `X_文体ルール` シートに出ます。**手で直せます。**
生成時はシートの内容を読むので、直した内容がそのまま効きます。

AIには**本文を書き換えさせていません。**判定と抽出だけです。

---

## ③ 生成の出力

2か所に出ます。

| シート | 用途 |
|---|---|
| `X_投稿案` | 1行1投稿。テーマ・本文・冒頭3行・狙いが並ぶ |
| `X_投稿案_週形式` | **いつものシートと同じ週ブロック形式。**そのままコピーして貼れる |

週形式では、生成した本文が `投稿文` の行に入り、`修正欄` は空です。
直したいときだけ `修正欄` を使ってください。**その差分が、次回の抽出の材料になります。**

## 設計上の約束

### 過去データは「文体」の教師、コンセプトは「内容」の担当

過去ログは文体の参考としてだけ渡しています。
内容は `これからのコンセプト` からだけ作ります。

生成プロンプトにも「過去の投稿例は文体の参考であって、テーマの参考ではありません」と
明示してあります。

### AIに本文を書き換えさせない

抽出は判定だけ。生成は新規作成だけ。
過去の投稿をAIに「整える」ことはしません。

### 禁止語を最優先のルールにしている

生成のシステムプロンプトで、禁止語を最上位の制約にしています。
`X_文体ルール` の禁止語を手で足せば、すぐ効きます。

---

## うまくいかないとき

| 症状 | 対処 |
|---|---|
| 読み取り0件 | `X_設定` の `対象シート名` `レイアウト` `▼ラベル列` `▼値の開始列/終了列` を確認。`読み取れるか確認する` のログを見る |
| 7本が1本に混ざる | `▼値の終了列` が未設定。`H` を入れる |
| 抽出が途中で止まる | 正常。**もう一度「文体を抽出する」を押す**と続きから |
| 最初からやり直したい | 「抽出をやり直す」→「文体を抽出する」 |
| 生成が止まる | `これからのコンセプト` が空。`X_設定` に入れる |
| 文体が似ていない | `X_文体ルール` の禁止語を手で足す。1語足すだけでかなり変わる |
