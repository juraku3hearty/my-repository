# ダンドリ — 開発計画 v1

**名称：ダンドリ**（段取り＋鳥。段取りを仕切る、よく喋る鳥のキャラクター名でもある）

家族の予定共有カレンダーではなく、家を回すための「段取りボード」。
コンセプト：**詳細は自分だけ、段取りは家族だけ。**

元仕様：Manus AI作成の依頼文（家族の段取りボード）をベースに、MAYUの技術資産・実運用に合わせて再設計。

## 設計原則（最重要）

> **家族は入力しない。返事するだけ。**

家族アプリが死ぬ理由の9割は「入力してくれない家族」。ダンドリは家族にアプリを開かせない。
いつものLINEにダンドリの方から聞きに来て（「今日の夕飯、いる？いらん？」）、ボタン1タップで義務完了。
自分から登録する人は家庭に1人いればよく、他の家族は「返事する人」。
鬼上司Bot・ハヨヤレで実証済みの「向こうから来るから続く」原理の家庭版。
成功指標は「旦那さんが毎日ボタンを押し続けるか」。

## 判断済みの方針

| 論点 | 決定 | 理由 |
|---|---|---|
| 規模 | **ガチ版（Webアプリ）でいく** | GAS/LINEだけでは家族ボードUIと権限分離が成立しない。MAYU了承済み |
| 技術スタック | **Next.js + Supabase + Vercel** | メルノキ・整骨院システムと同じ＝資産流用・運用ノウハウあり |
| 子どもの利用 | **LINE LIFF**（アカウント不要でLINEから開く） | 子どもに新規アカウントを作らせない。家族LINEは既に存在する。メルノキでLIFF実装実績あり |
| 通知 | **LINE**（家族グループ or 個別） | 日本の家庭の現実解。アプリPush（PWA）は後続 |
| 通知キャラ | **よく喋る鳥「ダンドリ」で確定** | 名前＝アプリ名＝キャラ。家中の伝言を運ぶ世話焼きな鳥は子どもにも刺さり、仕事シリーズ（おばちゃん・鬼頭課長）とブランドを分けられる。「明日体育やで！ジャージ！ジャージ！」と繰り返す芸が鳥と相性抜群 |
| Googleカレンダー連携 | **初期版から除外** | OAuth審査と抽象化実装が重い。v2で「可用性のみ参照」を検討。当面は「用事あり」を手入力 |
| LINE費用 | 顧客ごとに自分のLINE公式アカウントを持つ方式（既存製品と同じ0円構成）。通知は1日2回のダイジェストに集約して無料枠200通/月に収める設計 | |

## 🌟 キラー機能：行事カレンダーOCR自動入力（MAYU追加要件）

学校・園の月間プリント／年間行事表を**写真に撮って投げるだけ**で、段取りボードに自動入力する。

```
プリントを撮影 → LINEでダンドリに送る
  → Gemini Vision が日付・行事・持ち物を構造化抽出
     例）10/3 体育参観 → ジャージ洗濯（前日）、10/15 遠足 → 弁当・水筒
  → 段取りボードに「準備タスク」として自動登録（前日夜・当日朝にリマインド）
  → 誤読は「直して」で修正（ハヨヤレと同じ操作感）
```

- 技術実証済み：タイムカードOCR（No.2案件）と同じ Gemini Vision パターン
- 行事名から準備物を推論するのはAIの得意分野（体育→ジャージ、遠足→弁当・レジャーシート）
- **競合の共有カレンダーに存在しない差別化機能**。「プリント地獄からの解放」は保護者に一番刺さる訴求

## MVP機能（フェーズ1）

1. 親アカウント作成・家族グループ作成・子どものアカウント不要プロフィール（LIFF）
2. 「今日・明日・今週」の段取りボード（月間カレンダーは作らない）
   - カード：今日の夕飯（いる/いらん/未回答）／明日の準備／送迎の調整／帰宅の見通し／家族の都合
   - 未回答・未定・期限超過を最優先表示
3. 定型入力：「明日弁当いる」「金曜ジャージ洗っといて」「今日は夕飯いらん」→ ボタン＋短文
4. プライバシー分離：家族に見えるのは「予定あり／外出／帰宅目安／送迎要否」のみ。詳細は本人だけ
5. **行事カレンダーOCR自動入力**（キラー機能。フェーズ1に含める）
6. ダンドリ通知（LINE）：未回答の夕飯・未定の送迎・明日の準備を、1日2回のダイジェストで
7. 状態変更：完了／引き受け／不要／あとで

### やらないこと（フェーズ1）
位置追跡・交友関係の記録・家計管理・月間カレンダーUI・Googleカレンダー連携・Outlook対応

## フェーズ2以降の候補
- Googleカレンダー可用性連携（「父：13〜15時 予定あり」の自動化）
- PWAプッシュ通知
- 学校からのお便りメール転送→自動抽出
- 本人希望時のみ「家族の予定を自分のカレンダーに書き込む」

## 料金モデル（フリーミアム）

| | 無料版（まず配る） | 有料版（月額ワンコイン想定：500円/家庭 or 年額3,000円） |
|---|---|---|
| 段取りボード（今日・明日・今週） | ✅ | ✅ |
| 夕飯・弁当・送迎・帰宅・家事依頼 | ✅ | ✅ |
| LINE通知（ダイジェスト1日1回） | ✅ | ✅ 回数・時間帯カスタム |
| **行事カレンダーOCR自動入力** | ❌（体験1回だけ可） | ✅ 無制限 |
| 履歴・繰り返し設定 | ❌ | ✅ |
| Googleカレンダー連携（v2） | ❌ | ✅ |

- **キラー機能（プリントOCR）を有料側に置く**：AI処理コストが乗る機能でもあり、課金理由として一番説明しやすい。「体験1回無料」で価値を見せてから課金
- 無料版はバズリンク・note配布のネタとして機能（鬼上司・ハヨヤレと同じ導線でリスト獲得）
- 決済はメルノキ＋既存のRobopay/Square資産を流用

## 実運用計画

1. **最初の顧客＝平井家。** 自分の家で回らんもんは売り物にならん
2. 実地で1ヶ月運用 → 「本当に使った機能」でMVPを削る・磨く
3. バズリンク投稿ネタとしても使える：「学校のプリント、写真撮ったら段取り表になるアプリ作った」
4. SaaS化はメルノキ・整骨院と同じ道（自宅で実証→他家庭へ展開）

## 進め方

- 新規リポジトリ（例：dandori-app）で開発。このリポジトリはネタ帳・企画置き場として使う
- 名称は「ダンドリ」でほぼ確定（段取り＋鳥のダブルミーニング。MAYU発案）
- 着工タイミング：ハヨヤレのバズリンク投稿・配布導線が完全に片付いてから
