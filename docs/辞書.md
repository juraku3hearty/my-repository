## 2. 手順メモ

### 2-1. コンセプトを決めるには（第2章）
1. 経験の棚卸し：①時間やお金を使ってきたこと ②人から相談されたこと ③失敗しながらできるようになったこと
2. 経験がゼロなら「弟子ポジション」（教材で学び、実践過程を発信）で始める
3. ジャンルを絞る（「AI」→「AI×動画編集」レベル）。絞りすぎて自分の経験から外れたら絞りすぎ
4. AIで**この講座用の新しい会話**を1つ開き、コンセプト整理プロンプトを送る → 3案から1つ選ぶ
5. 確認基準：「この人は何について発信する人？」に答えられるか
6. **この会話は残す**（第3章以降で使う）

### 2-2. プロフィールを整えるには（第3章）
1. 名前 = `名前｜何の人か`（表示名。@ユーザー名ではない）
2. アイコン：小さく表示されても見分けられるもの。文字を詰め込まない
3. プロフィール文：3要素、160文字以内。1行目で「発信を読む理由」を伝える
4. 実績は「何の数字か」まで。ない人は「今やっていること／これからやること」を書き分ける
5. 同じAIの会話の続きでプロフィール生成プロンプト → 1行目3案から選ぶ
6. Xアプリ → プロフィールを編集 → 名前 / 自己紹介 / 画像 → 保存
7. 実表示で確認。X上で直したら、その内容もAIに伝えて確定版をそろえる

### 2-3. 紹介するBrainを決めるには（第4章）
1. 基準はコンセプト。「なぜ自分がこれを紹介するのか」を自然に説明できるか
2. 候補の探し方：発売予告 / 販売中 / 過去に買ったもの
3. 商品ページで確認：①誰向けか ②何に取り組むのか ③必要なツール・機材・前提（有料ツール契約なら利用料も）
4. **紹介条件**（購入者限定か）と**紹介報酬率**を購入前に確認
5. 価格・値上げ・販売期限を確認（購入時と紹介時は別々に確認）
6. 購入したら**まず1つ実践する**（完璧を目指さない。迷った所も覚えておく）
7. 同じAIの会話で実践記録を整理（プロンプト）
8. 「誰に・なぜ勧めたいか」を説明できるか判断 → 紹介しない選択もOK

### 2-4. 感想を作るには（第5章）
1. 6材料（1-C参照）を用意。「良さそう」しか書けない＝確かめていない
2. 一番伝えたい良さを**1つ**決める（他を書くなというわけではなく、中心を決める）
3. 冒頭で商品名と自分の立場を伝える
4. 「機能説明」ではなく「何を頼んで、どう感じたか」まで書く
5. よかったところ → **なぜ自分にとってよかったのか** をつなげる
6. 勧めたい相手を具体化（「AIに興味がある人」→「AI動画を作りたいが最初のツールが分からない人」）
7. 同じAIの会話で感想プロンプト → 出力を全文読み、事実・数字・自分の言葉に合っているか確認
8. 直すときは「強い言葉を増やす」ではなく「具体的な経験と理由を増やす」

### 2-5. 特典を作って配れる状態にするには（第6章）
1. 「この商品の購入を考えている人が、次に欲しくなるものは何か」から考える
2. 商品 × 自分の得意分野 で掛け合わせる。まずは1つ
3. 同じAIの会話で 特典候補プロンプト（最大5案）→ 1つ選ぶ
4. 特典本体プロンプトで中身を作る（形式別：チェックリスト／テンプレート／AIプロンプト／実践メモ／伴走支援）
5. 特典名：何がもらえて何に使えるか分かる名前を3案出させて選ぶ
6. 配布用Googleドキュメントにまとめる：**特典名 → 何に使うものか → 使い方 → 特典本体**
7. 共有設定：一般的なアクセス「リンクを知っている全員」／権限「閲覧者」→ リンクをコピー

## 3. 判断基準・原則

### 3-1. なぜ紹介から始めるのか（3つの理由）
1. **自分の商品を完成させる前に「売る」経験ができる** — 古着転売で自分のブランドを作らないのと同じ
2. **フォロワーが増えるまで待たなくていい** — 販売者の告知を引用、リポストで自分のフォロワー外にも届く可能性（ただしリポストは販売者の判断。本人が書いたと分かる感想が必要）
3. **特典で「自分から買う理由」を作れる** — 知名度がなくても、相手が欲しいものは用意できる

### 3-2. なぜ最初から高単価を狙わないのか
- 報酬が大きいのは「売れた場合」の話。買う人が安心して払えるかも考える
- よく知らない人から30万円の講座を勧められても判断できない
- 紹介した**後**に相手が受ける説明・セールスも自分の信用に関わる
- 高単価案件の多くは「集客を手伝う」役割。販売者に拡散も期待するのは役割が逆
- Brainは自分で買って中身を確認でき、購入者もレビューと価格を確認できる

### 3-3. 事実の扱い（全プロンプト共通の禁止事項）
- 存在しない経験・実績・数字・発言を作らない
- 「読んだ／試した／完成した／公開した／売れた」を区別する
- 売上 / 利益 / 紹介報酬 を混同しない。期間合計を月間に変えない
- 他人の実績・教材内の見本を自分の情報にしない
- 自分の結果を「誰でも同じ結果になる」に広げない
- 商品の機能説明と、自分が経験したことを分ける
- 別の商品の経験・成果を今回の商品へ移さない

### 3-4. 有料教材と自分の経験の線引き（第8章）
- 購入した教材の本文・収録プロンプトを、そのまま記事に載せない
- 購入は転載・公開の権利を得ることではない（著作権で保護される表現を含む）
- 出典を書けば何でも載せてよいわけでもない（引用には必要性・範囲・区別などの条件がある）
- 記事で伝えるのは「自分が何に取り組み、何が分かったか」

### 3-5. AIの使い方の原則
- プロンプトはコピペ。質問に答える（音声入力でもよい、うまい文章にしなくてよい）
- 質問は1回1つ、回答するまで次に進ませない
- 第1部は同じ会話を続ける／第2部はナレッジ＋スキルで再利用可能にする
- AIに強い言葉を足させるのではなく、自分が確かめたことを1つ入れる
- 経験そのものはAIに作らせない。AIは整理と文章化を担当する
