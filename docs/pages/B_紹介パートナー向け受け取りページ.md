# 受け取りページB（紹介パートナー向け）

> 流入元：記事⑩
> 読者：税理士・社労士・制作会社・Web会社・予約システムの導入支援者
> 渡すもの：ヒアリング用 3つの質問シート
> Aとはトーンを変える。**売り込まない。相手の仕事に使ってもらう**のが目的

---

## ■ ファーストビュー

### 見出し
```
顧問先・クライアントの「社長詰まり」を見分ける3つの質問
```

### サブ
```
打ち合わせでそのまま使えるシートです。紹介前提ではありません。
```

---

## ■ 届くもの

```
記事で書いた3つの質問を、打ち合わせで使える形にしました。
```

```
・3つの質問の文面（そのまま読める形）
・回答別の見立て表（A／B／C の3パターン）
・「誰かが無料で吸収していないか」の確認欄
・印刷用とスプレッドシート版
```

```
月次面談や打ち合わせのときに1枚挟んでおけば、それで終わります。
使うだけ使ってもらって大丈夫です。
```

## ■ 私がやらないこと（ここが一番大事だと思っています）

```
・税務・労務・法務の判断はしません
　業務範囲として含まないと定義しています。該当する話が出たら、整理して先生にお返しします

・制作・開発は取りません
　新規アプリ開発、大規模な自動化は請けません。
　私がやるのは、納品されたものが現場で使われる状態にするところです

・記帳代行・給与計算の代行はしません

・顧問契約を取りに行きません

・データとアカウントを囲い込みません
　作ったものは全部その会社に残します
```

```
逆に、現場に入ると必ず外に出す案件が出ます。

・労務の論点が出てきたら → 社労士の先生へ
・税務の判断が要るなら → 税理士の先生へ
・サイトやシステムの実装が必要なら → 制作会社・Web会社さんへ

そのときは、こちらからお願いさせてください。
```

## ■ 紹介いただいたあとの流れ

| | |
|---|---|
| ① | Google Meetで30分。見立てだけ。解決作業はしません |
| ② | 必要なら、翌日までに提案をお送りします |
| ③ | **不要なら「今は不要です」と言います** |


## ■ 紹介のタイミングについて

```
一番価値があるのは、この情報です。

「ずっと全部やってくれてた人が辞めた／辞めそう」

社長に直撃していて、しかも引き継ぎができない状態なので。
中身を知っているのが、辞める本人だけなんですよね。

逆に、社長の仕事を無料で吸収している人がいる会社は、
社長に痛みが出ていないので、紹介いただいても「今は不要です」とお答えします。
```

## ■ ページに置かないもの

| 置かない | 理由 |
|---|---|
| **紹介料の話** | 本人未決定。相手に既存の慣習がある可能性があるため、こちらから決め打ちしない。聞かれたらその相手のやり方に合わせる |
| 料金表 | 同上 |
| 顧客名 | 守秘。業種と作業種別までに留める |
