# 受け取りページA（社長向け）

> 流入元：固定ポスト／記事①②③
> 渡すもの：棚卸しシート＋判断基準の言語化シート（**2枚セットで1オファー。選ばせない**）
> 同一ページに30分相談のカレンダーを置く。ページを分けない
> 原則：このページの仕事は「シートを渡す」と「相談枠を押させる」の2つだけ。
> 　　　料金表・サービス一覧・実績一覧は載せない（本人の「使わない機能で画面がごちゃごちゃしない」に従う）

---

## ■ 届くもの（2枚）

```
判断を渡すのは、2段階です。
どの業務から外すかを決めて、その業務の判断を書き出す。
その2つを、そのまま埋められる形にしました。
```

**① 1業務を決める棚卸しシート**

```
・いま抱えている業務を並べる欄
・週の回数 × 1回の分数 で、削減見込みが出る
・「選んではいけない業務」のチェックリスト
・完了条件を先に決める欄
```

**② 判断基準の言語化シート**

```
・例外判断／程度判断／順番判断の3枠
・「もし〜なら、〜する／理由」の記入欄
・記入例つき
・渡さないものを決める欄（お金・人・外への約束）
```

```
印刷用とスプレッドシート版が入っています。
1業務分、埋めれば終わる形にしてあります。
```

## ■ 30分の無料相談

```
シートを見て「そもそもどの業務から手をつけたらいいか分からん」
となったら、30分だけ話しませんか。

「めんどくさいこと相談」という枠です。
```

| | |
|---|---|
| **形式** | Google Meetで30分 |
| **費用** | 無料 |
| **やること** | どこが詰まっていて、何から直すと一番効くかを見立てる |
| **やらないこと** | その場で解決作業まではしません。見立てだけです |
| **持ち帰り** | 整理した内容は、そのまま持って帰ってもらって大丈夫です |

```
見立てた結果、自分たちでできそうなら「それでいけます」と言います。
手が足りないだけなら「人を増やしたほうが早いです」と言いますし、
今は不要なら不要と言います。

手を入れたほうがいい場合だけ、あらためて有料でのご提案をお送りします。
そこで断ってもらって、もちろん大丈夫です。
```

**［カレンダー］空いている枠から選んでください**

```
これは「100人のめんどくさいをAIで解決するチャレンジ」の枠としてやっています。
```

**［残り枠数をここに表示：◯／100］** ← ページ側で更新する。記事には書かない


## ■ ページに置かないもの

| 置かない | 理由 |
|---|---|
| 料金表 | 相談後の提案書で出す。先に出すと見立ての前に判断されてしまう |
| サービス一覧（顧問・伴走） | このページの仕事は2つだけ。増やすと両方の行動率が落ちる |
| 実績一覧・お客様の声 | 声はまだ準備中。無いものは載せない |
| 記事一覧 | 記事からこのページに来ている。戻す導線は要らない |

---

## ■ ページ側で更新するもの（記事には書かない）

- 100チャレの残り枠数
- 相談枠の空き日程
- シートの内容を追加・変更したとき

**この3つをページに置いておけば、記事を二度と編集しなくて済みます。**
