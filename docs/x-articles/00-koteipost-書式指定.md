# 固定ポストの書式指定（X Premium Articles用）

## 手順

1. `00-koteipost-plain.txt` を全文コピーしてエディタに貼る
2. 下の行に**太字**を当てる
3. タイトルとカバー画像を設定する
4. 公開
5. 受け取りページができたら `00-koteipost-plain-cta.txt` を追記して更新

---

## タイトル

```
社長語を、現場語に
```

**サブタイトルが設定できる場合：**
```
手順は渡せても、判断は渡っていなかった
```

---

## カバー画像に入れる文字（作るなら）

```
社長語を、現場語に
```
左に「社長」、右に「現場」、間に切れた矢印。
※記事①と共通デザインにして、シリーズとして並ぶ形にする。

---

## 太字にする行（9箇所）

上から順に。これ以外は太字にしない。

| # | 太字にする行 |
|---|---|
| 1 | 社長語が、まだ現場語になっていないだけかも。 |
| 2 | ただ、同じ会社の中で、／社長語がまだ現場語になっていない。 |
| 3 | 院長の頭の中にあるものを、／スタッフが動ける言葉や手順に変える。 |
| 4 | 現場で起きていることを整理して、／院長が判断できる形に戻す。 |
| 5 | 私は、AIを入れたいわけじゃない。 |
| 6 | 大事なのは、／頭の中にあるものが、／相手に伝わって、／実際に動ける形になること。 |
| 7 | 手順は渡せていても、／判断は渡っていない。 |
| 8 | 社長語を、現場語に |
| 9 | 社長にしかできない仕事へ戻ってもらう。 |

### 太字にしないもの

- 「社長と現場の翻訳室」 … カギカッコで十分立っている
- 「小さな事業の外部の裏方」 … 同上
- 社長／現場のセリフ（「こうしたい」等） … カギカッコで区切られている
- AIの列挙4行 … リスト扱いなので太字にすると重い

**太字が9箇所で、1,132字に対して多すぎるようなら 1・5・7・8 の4箇所だけでも成立します。**
この4つで「症状 → 立場 → 原因 → 結論」の骨が通ります。

---

## 見出しを使う場合

Articlesで見出しが使えるので、区切りに入れてもよい。
ただし固定ポストは短いので、入れなくても読めます。入れるならこの4つ。

| 位置 | 見出し |
|---|---|
| 「たぶん、こういう状態に」の前 | 社長と現場で、言葉が通じていない |
| 「私は15年以上」の前 | 15年、その間に入っていました |
| 「最近はAIや自動化も」の前 | AIを入れたいわけじゃない |
| 「冒頭の」の前 | 渡っていなかったのは、判断でした |

---

## 箇条書きにする行

AIの列挙4行を、エディタの箇条書き機能で組む。

```
AIが必要なら使う。
マニュアルへの追記で済むなら、それでいい。
チェックリストが合うなら、それでいい。
人に任せた方がいいなら、そうする。
そもそもやらなくていい仕事なら、なくしてもいい。
```

※1行目「AIが必要なら使う。」も含めて5項目。

## 公開後にやること

| | やること | 条件 |
|---|---|---|
| 1 | プロフィールの名前欄を「平井まゆみ｜翻訳プロデューサー」にする | すぐ |
| 2 | プロフィール本文を差し替える（下記） | すぐ |
| 3 | この記事を固定する | すぐ |
| 4 | CTAブロックを追記 | 受け取りページ公開後 |
| 5 | 記事①へのリンクを追記 | 記事①公開後 |

### プロフィール本文（120字）

```
社長と現場のあいだに立って、社長の頭の中を現場が動ける形にする外部の裏方です｜夫の整骨院で経理・人事・現場を15年、ほぼひとりで｜従業員1〜10名の店舗業・サービス業の社長向け｜「社長語を、現場語に」の話を固定ポストに書きました
```

※末尾の「固定ポスト引用で気軽に相談どうぞ」は外す。
　記事のCTAが受け取りページになるため、引用導線と二重になる。
