**なぜ軽いやつから始めるのか**

重い判断から渡して何か起きると、たいてい社長が全部引き取ってしまいます。

取り上げると、二度と渡せなくなります。

1個目の目的は、時間を減らすことじゃなくて、

### STEP2：「もし〜なら、〜していい」の形で1行書く

選んだ質問を、1行のルールに変えます。

```
もし 備品が残り3個を切ったら → 発注していい（私に確認しなくていい）
理由：切らすと現場が止まるから。多少多く頼んでも困らない
```

ポイントは**理由を1行つけること**です。

理由がないと、書いてある場面しか対応できません。

理由があると、書いてない場面でも自分で判断できます。

「切らすと止まる」が分かっていれば、備品以外でも同じ判断ができます。

手順を増やすんじゃなくて、**判断の軸を1本渡す**。

これが「渡す」ということです。

**なぜ1行なのか**

ちゃんとした文書を作ろうとすると、着手しません。

実際、LINEで送ってください。それで完了です。

## 先回りで答えておきます

### 「渡したら勝手なことをされそうで怖い」

全部渡す必要はないです。むしろ全部渡したら事故ります。

**渡さないものを先に決めてください。**

- お金が出ていく判断（金額の線を決める。「1万円以上は確認」とか）
- 人に関する判断（採用、シフトの大きな変更、評価）
- 外への約束（値引き、納期、新規取引）

ここは渡しません。

そして面白いのは、**渡さないものを明文化すると、それ以外が自動的に「聞かなくていい」に変わる**ことです。

スタッフが一番怖いのは「勝手にやって怒られること」です。

渡してもらえないから聞いてるんじゃなくて、どこまでが自分の範囲か分からないから聞いてます。

禁止を決めると、自由が増えます。

### 「うちのスタッフはそこまで考えてくれない」

その可能性はあります。

ただ、3年間「聞けば答えが返ってくる」環境にいた人が考えないのは、

性格ではなく学習の結果かもしれません。

1個渡してみて、それでも動かなかったら、そのときは人の問題として考えればいいです。

**順番として、環境の方を先に確認してください。**

### 「忙しくて、ルールを書く5分もない」

その5分が取れない状態こそが、この記事の主題です。

今日やらないなら、来年も同じ記事を読んでます。
