# おもしろ業務効率化アプリ ネタ帳

> 「実際少し役に立つけど笑っちゃう」を量産して note でバズらせる → そこからしっかりした SaaS に繋げる作戦。
> 判定基準はいつも通り「GAS + LINE + スプシで作れるか」を最優先。

## 出発点の4案 実現性判定

### 1. 🔥 鬼上司Bot（しつこい上司）— 判定: ◎ 即作れる

カレンダーに空きがあると LINE が飛んでくる。「おい、明日の14時ガラ空きだぞ。仕事入れろ」

- **技術:** GAS 時間トリガー（朝夕2回）→ Googleカレンダー空き検出 → LINE Messaging API で Push
- **工数:** 半日
- **仕掛け:** 放置すると口調がエスカレートする（1回目は丁寧 → 3回目「サボりか？」）
- **実益:** 予定を入れる習慣がつく。ガチで営業職に売れる可能性すらある
- **状態:** 公開済み・全自動配布中。**メール配信専用で確定**（LINE不要のGEMINI_API_KEYだけ5分セットアップが配布標準。件名芸【至急】【再送】【人事評価】はメールでこそ成立）

### 2. ⌨️ ミスタッチ説教アプリ — 判定: ○ GAS不可、Chrome拡張なら1日

Backspace を30回叩くと画面いっぱいに怒りのオーバーレイが出る。「落ち着け。深呼吸しろ。」

- **技術:** Chrome 拡張（keydown で Backspace カウント → 閾値でフルスクリーン説教モーダル）
- **注意:** OS全体のキー監視はアプリ化（AutoHotkey/Electron）が必要。まずはブラウザ内限定で十分笑える
- **工数:** 1日
- **実益:** タイプミスの自覚。休憩の促し

### 3. ☎️ モーニングコール（指定した声で電話）— 判定: △ LINE電話は不可、代替2ルートあり

- **LINE通話の自動発信は API が存在しない → 不可能**
- **代替A（無料・◎）:** TTS で生成した音声を LINE ボイスメッセージとして毎朝 Push。「起きろ」を好きなキャラ声で
- **代替B（有料・◎）:** Twilio で本物の電話をかける + 合成音声。1通話 数円。これは本当に電話が鳴るので破壊力が違う
- **声の生成:** AI音声生成（ボイスクローン含む）で「社長の声」「推しの声」も技術的には可能

### 4. 🤬 暴言リマインダー — 判定: ◎ 即作れる（キャラ設定が炎上回避のカギ）

リマインドが毎回口悪い。「まだやってへんの？知ってたわ。どうせやってへんと思った」

- **技術:** GAS + LINE + Gemini API（無料枠）。リマインド文を毎回 Gemini に生成させるので同じ暴言が二度と来ない
- **キャラ設定:** 「口は悪いが憎めない関西のオカン」「ツンデレ秘書」等を選択制に → 単なる暴言ではなく"芸"になる
- **工数:** 半日
- **実益:** 普通のリマインダーより既読率・実行率が上がる（たぶん。noteの検証ネタになる）

## 🖤 愚痴デスノート — 判定: ◎ ただし設計変更1点

黒い画面に上司や会社の名前を書く（儀式感）→ 愚痴を吐く → AIが全力で同調して一緒にキレてくれる。深夜0時、書いた愚痴は燃えて消える（供養演出）。

- **技術:** LINE Bot（GAS + Gemini）または Web1枚。キャラは「全肯定でキレ散らかす親友」
- **設計変更:** 「ネット検索で実在人物の情報を収集して悪口生成」は**やらない**。売り物・note公開前提だと名誉毀損リスクを運営側が背負う。検索がなくても「AIが自分の側に立って一緒に怒ってくれる」快感は変わらない
- **むしろ強化:** 0時に愚痴が燃えるアニメーション → ログ完全削除。「証拠が残らない」ことが安心感＝売りになる
- **実益:** メンタルケア。社内グループへの誤爆・SNSでの本音漏洩を防ぐ「吐き出し先」
- **姉妹品:** 妄想退職届ジェネレーター（辞表を書いてスッキリするだけ。提出はしない）

## 📢 ハヨヤレ（Slack版おばちゃんリマインダー）— 2本目に正式決定

登録した上司からのSlack連絡を、関西弁おばちゃんが**全自動で**聞き耳を立てて拾う。
Geminiが「依頼かどうか」を判定し「何を・いつまでに」を抽出して自動登録 → 期限が近づくとDMで詰めてくる。
「あんた、金曜までの資料あるやろ。上司さんの顔思い出してみ？はよやり！」

- **方式:** 全自動監視（手動だと拾い忘れて漏れるため）。拾った瞬間に「登録しといたで。違ってたら『ちゃう』て返しや」と確認DM＝誤検知は一言で取消
- **権限:** チャンネル監視はBot招待だけ／上司からのDM監視は自分のユーザートークンで自分宛DMを読む方式（両対応）
- **技術:** GAS（SlackイベントをWebアプリURLで受信）＋ Slack API（無料）＋ Gemini無料枠 → **完全0円・通数制限なし**（LINE版の月200通の壁が存在しない）
- **完了:** ✅リアクション or「やった」返信 → 「えらいやん！飴ちゃんや🍬」
- **追加芸:** 催促の絵文字がエスカレート（😤→💢→👹）／金曜夕方に未完了の棚卸し
- **流用:** LINE版おばちゃんのキャラ定義・Gemini・催促ロジックが6割使える。実装1日
- **状態:** 公開済み（2026-09-03 バズリンク投稿）。**Slack・Chatwork専用で確定**（LINE版は作らない。家庭向けLINE枠はダンドリが担当）

## 💰 コスト戦略（LINE 月200通の壁への対策）

LINE公式アカウントの無料枠は**Push（こちらから送る）が月200通**まで。超えるとライトプラン5,000円/月。
ただし**応答メッセージ（ユーザーの送信へのreply）は無料・無制限・カウント外**。ここが最大の抜け道。

### 分類すると

**✅ 完全無料でいける組（reply型 = 何万通でも0円）**
- 愚痴デスノート（ユーザーが愚痴を送る→返す。全部reply）
- 上司翻訳機 / 謝罪文・断り文・やってる感ジェネレーター（貼る→返す）
- 優柔不断斬りBot
- 会議時給メーター / 会議ビンゴ / ミスタッチ説教（そもそもWeb/拡張なのでLINE不要）

**⚠️ Push節約が必要な組（鬼上司・帰れ・月曜憂鬱・モーニングコール）**
- 200通/月 ÷ 30日 ≈ **1日6通まで**。自分ひとりで使う分には鬼上司Bot朝夕2通=月60通で余裕
- 配布時は「顧客が自分のLINE公式アカウントを作る」方式（献立AI No.1と同じセットアップ）→ **1顧客ごとに200通の無料枠が付く**ので、MAYU側の課金は発生しない
- エスカレート演出は「未応答なら翌回強くなる」方式にして通数は増やさない

### Push無料の代替チャネル
- **LINE Notifyは2025年3月にサービス終了済み**なので使えない。代わりに：
- **Discordのwebhook** — 無料・無制限。Claudecord顧客はすでにDiscordにいるので相性最高
- **Gmail（GAS MailApp）** — 無料枠1日100通。「鬼上司からのメール」はむしろ演出として正しい
- **Webプッシュ通知（PWA）** — 無料・無制限。iPhoneもiOS16.4以降対応

### モーニングコール改訂
Twilio実電話はバズ動画用の一発ネタに格下げ（自分のデモ用に数十円払うだけ）。常用版は「朝一に鬼上司からLINE/メールが来る」で十分成立。
