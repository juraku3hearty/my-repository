# おもしろ業務効率化アプリ ネタ帳

> 「実際少し役に立つけど笑っちゃう」を量産して note でバズらせる → そこからしっかりした SaaS に繋げる作戦。
> 判定基準はいつも通り「GAS + LINE + スプシで作れるか」を最優先。

## 出発点の4案 実現性判定

### 1. 🔥 鬼上司Bot（しつこい上司）— 判定: ◎ 即作れる

カレンダーに空きがあると LINE が飛んでくる。「おい、明日の14時ガラ空きだぞ。仕事入れろ」

- **技術:** GAS 時間トリガー（朝夕2回）→ Googleカレンダー空き検出 → LINE Messaging API で Push
- **工数:** 半日
- **仕掛け:** 放置すると口調がエスカレートする（1回目は丁寧 → 3回目「サボりか？」）
- **実益:** 予定を入れる習慣がつく。ガチで営業職に売れる可能性すらある

### 2. ⌨️ ミスタッチ説教アプリ — 判定: ○ GAS不可、Chrome拡張なら1日

Backspace を30回叩くと画面いっぱいに怒りのオーバーレイが出る。「落ち着け。深呼吸しろ。」

- **技術:** Chrome 拡張（keydown で Backspace カウント → 閾値でフルスクリーン説教モーダル）
- **注意:** OS全体のキー監視はアプリ化（AutoHotkey/Electron）が必要。まずはブラウザ内限定で十分笑える
- **工数:** 1日
- **実益:** タイプミスの自覚。休憩の促し

### 3. ☎️ モーニングコール（指定した声で電話）— 判定: △ LINE電話は不可、代替2ルートあり

- **LINE通話の自動発信は API が存在しない → 不可能**
- **代替A（無料・◎）:** TTS で生成した音声を LINE ボイスメッセージとして毎朝 Push。「起きろ」を好きなキャラ声で
- **代替B（有料・◎）:** Twilio で本物の電話をかける + 合成音声。1通話 数円。これは本当に電話が鳴るので破壊力が違う
- **声の生成:** AI音声生成（ボイスクローン含む）で「社長の声」「推しの声」も技術的には可能

### 4. 🤬 暴言リマインダー — 判定: ◎ 即作れる（キャラ設定が炎上回避のカギ）

リマインドが毎回口悪い。「まだやってへんの？知ってたわ。どうせやってへんと思った」

- **技術:** GAS + LINE + Gemini API（無料枠）。リマインド文を毎回 Gemini に生成させるので同じ暴言が二度と来ない
- **キャラ設定:** 「口は悪いが憎めない関西のオカン」「ツンデレ秘書」等を選択制に → 単なる暴言ではなく"芸"になる
- **工数:** 半日
- **実益:** 普通のリマインダーより既読率・実行率が上がる（たぶん。noteの検証ネタになる）

## 開発順（笑い × 実益 × 工数で決定）

1. **鬼上司Bot** — 半日で完成、note映え最強、体験者を募集しやすい
2. **暴言リマインダー** — 鬼上司Botとコード8割共通。キャラ選択制で横展開
3. **帰れBot** — 上2つのトリガー違いなのでほぼコピペで完成（3本目のnoteが1日で書ける）
4. **謝罪文ジェネレーター** — Bot連作に飽きた頃の変化球
5. **ミスタッチ説教** — Chrome拡張の練習台としてちょうどいい
6. **モーニングコール** — Twilio版は「本当に電話が鳴る」動画がSNS向き。バズ狙いの飛び道具

## 戦略メモ

- 1〜3はコードの共通部分（LINE Push基盤 + GASトリガー + Gemini文面生成）を1回作れば量産できる。**「おもしろBotシリーズ」として週1本 note を出せるペース**
- 笑いで入口を作る → 「これ作った人、ガチの業務システムも作れます」で 100チャレ・Claudecord に導線
- 動いたコードは資産庫（`~/.claude/assets/`）に登録して部品化
