## 何が起きるか（1日の流れ・そのまま図解ネタに使えます）

勤務時間（初期設定 9〜18時）のカレンダーが半分以上空白だと、1時間ごとに監視している鬼頭課長が動き出します。

| 時間 | 鬼頭課長の攻撃 |
|---|---|
| 9時 | 説教メール1発目「おい、今日もカレンダーがスカスカだぞ」 |
| 10時 | 件名「【至急】カレンダーの件」 |
| 11時 | **勝手にカレンダーに「【緊急】鬼頭課長との面談（カレンダーが空白の件）」という予定を入れてくる**（スマホに通知も来る） |
| 12〜13時 | 件名「【再送】読んでいるか？」「【重要】俺は怒っていない。悲しんでいるだけだ」 |
| 14時 | 最終通告「明日の朝もカレンダーが白かったら…俺は泣くぞ」 |
| 15時〜 | それでも毎時メールは止まらない |

- 予定をちゃんと入れると→ 件名**「【人事評価】見直した」**のメールで照れながら褒めてくれる
- サボりが翌日も続くと→ 説教レベルが上がる（軽い注意→圧→ブチギレ→呆れ）
- 休日は黙る。ただし「休日おせっかいモード」だと、**休みの日に予定ゼロなら「休みなのに何も予定が無いのか！遊びに行け！全力で休むのも仕事のうちだ！」と怒られる**

## 実際のセリフサンプル（引用OK・スクショ映えポイント）

説教文はAIが毎回生成するため、同じ説教は二度と届きません。以下は実例のトーンです。

> お疲れさん。今日のカレンダー、8時間も空いてるみたいだが…何か入れなくて大丈夫か？

> また空白か。サボりか？サボりなんだな？今すぐ何かひとつでいい、予定を入れろ。

> …もういい。俺がお前のカレンダーに「反省会」を入れておいてやろうか。ん？

メール件名シリーズ（進行順）：
「【至急】カレンダーの件」→「【再送】読んでいるか？」→「【重要】俺は怒っていない。悲しんでいるだけだ」→「【最終確認】カレンダーを見ろ。俺も見ている」→「【業務連絡】もはや意地になっている」→「【自動送信ではない】心を込めて送っている」→「【本日最終便】明日の俺に期待させてくれ」

カレンダーに勝手に入る面談予定の中身：
> 議題: なぜカレンダーが真っ白なのか。
> 持ち物: 反省の色。

## キャラクター設定（鬼頭課長）

昭和の熱血が抜けない鬼上司。口は悪いが根は誰よりも部下想いで、説教の最後に必ず本音がにじみ出てしまう。人格攻撃・差別的な発言は一切しない設計（AIへの指示レベルで禁止済み）。
