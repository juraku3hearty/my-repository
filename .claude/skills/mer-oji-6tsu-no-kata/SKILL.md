# X記事生成スキル

## 概要
ジャンルとターゲットに合わせたX記事（長文投稿）を生成する

## ワークフロー
1. CLAUDE.mdの自社情報からジャンル・ターゲットを確認
2. ユーザーに確認した上で、テーマ案を10個提案
3. ユーザーが1つ選択
4. 6つの型を組み込んだ記事を生成（8,000〜10,000字）

## 6つの型

### ① タップ設計
- タイトル：数字＋簡易性＋絶大な効果
  - 数字（例：「151万インプ」「3つの方法」）
  - 簡易性（例：「小学生でもわかる」「コピペ1回」）
  - 絶大な効果（例：「完全自動化」「月100万」）
- サムネ：タイトルのキーワードを視覚化、シリーズ感のある統一デザイン、タイムラインで埋もれない配色（黒×黄、赤×黒など）
- 冒頭3行：あるある型 or 実例提示型 or 言い切り型
  - あるある型：共感＋問題定義
  - 実例提示型：ありえない事実を見せる
  - 言い切り型：差別化を宣言する
- ※タイムラインに表示されるのは本文の最初の3行だけ。ここでタップされるか決まる

### ② 冒頭フック
- 共感 → 問題定義 → 立場宣言 の順
  - 共感：「最近Xで○○の記事めちゃくちゃ流れてきますよね」
  - 問題定義：「でも正直どれもめちゃくちゃ難しくないですか？」
  - 立場宣言：「だから僕（私）がこの記事を作りました」

### ③ 特徴宣言
- 「この記事はこういう記事です」を明示
- 「この記事を読むとこうなります」を約束
- 例：「選択肢を提示しません。『これをやってください』だけ」「専門用語は全部その場で説明します」「コピペする部分は全て矢印↓で示します」「100%できます。保証します」

### ④ STEP設計
- 「やることは○つだけ」で心理ハードルを下げる
- 手順を迷わせない構成
- 「なぜこれをやるのか」を全STEPに添える（理解を伴わない作業は続かない）
- 困ったときの解決方法を入れる（エラーが起きそうなポイントは先回りで潰す）

### ⑤ CTA設計
- プレゼントは1個に絞る（複数並べると行動率が落ちる）
- 「絶対に欲しい」プレゼントを設計する
- オプチャ→LINEの2段階導線
  - オープンチャット → 公式LINE友だち追加 → キーワード送信 → 自動配布
  - 理由：公式LINEはBANリスクがある／オープンチャットはBANリスクなし＋送信コスト0

### ⑥ 回遊構造
- 記事の最後に「次の記事」を貼る
- 関連する過去の記事を貼る
- 「フォローよろしくお願いします」
- 「引用で感想いただければ全リポストします」
- 効果：滞在時間が伸びる／フォロワー転換率が上がる／アルゴリズム評価が上がる／CTA到達者が増える

## 鉄則
感情→論理→簡単さ。この順番を守る

## 文体ルール
- 1文は短く。改行多用。スマホスクロール前提
- 丁寧語ベースだがカジュアルで熱量が高い
- 専門用語は初出時に必ず1行で説明
- 読者に選択肢を与えない。「これをやってください」だけ

## このアカウント固有の設定（MAYU）

### ジャンル
- AI業務自動化（GAS / LINE / スプレッドシート / Claude Code）
- 非エンジニアでも回せる「現場の自動化」

### ターゲット読者
- 中小企業・個人店の現場スタッフ（整骨院・サロン・士業など）
- プログラミング未経験〜独学レベル
- 「AIで楽になりたいが何から触ればいいか分からない」層

### トーン
- カジュアル丁寧語。現場staff目線。専門用語は都度かみ砕く
- 「経営者の妻が独学でここまでやった」という当事者視点を前面に出す

### 実績（記事内で使える素材）
- 100チャレ：AI自動化を100人に無料提供する取り組み
  - No.1 献立AIシステム（LINE Bot × GAS × Gemini で1ヶ月の献立と買い物リストを自動生成）
  - No.2 タイムカードOCR＋VBA転記（弁護士の未払給料裁判案件。Gemini Vision で画像を読み取り、裁判所提出用Excelへ自動転記）
  - No.3 ディオーネバレーボール YouTube自動アップロード（フォーム投稿→YouTube自動公開。本番稼働中）
- Claudecord：Claude Code × Discord 連携の有料サービス

### 技術選定の原則（記事内の主張として使う）
- まずGAS・LINE・スプレッドシートで実現できるかを検討する
- それで無理な時だけアプリ化する

### CTA（プレゼントは必ず1個に絞る）
- 導線：オープンチャット → 公式LINE → キーワード送信 → 自動配布
- プレゼント候補（記事テーマに合わせて1つだけ選ぶ）
  - 記事で紹介したGASコード一式（コピペで動く状態）
  - LINE Bot初期セットアップ手順書
  - 100チャレ無料相談枠
