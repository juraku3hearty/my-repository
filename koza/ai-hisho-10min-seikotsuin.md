# 整骨院版「院の秘書室」10分セットアップ（講座用教材）

## 想定受講者

- 整骨院の先生・スタッフ
- ChatGPTは触ったことがある / PCはそこそこ
- プログラミングはしない

## 使うもの

**ChatGPTの「プロジェクト」機能**（開発者向け画面が出ないもの）を使う。
リポジトリ選択や環境設定が出るツールは、この層では最初の1分で離脱するため使わない。

追加課金なし。既存のChatGPT契約のみ。

---

## 講座10分の進行台本

最初の3分で「文章が出てくる快感」を必ず体験させる。設定作業は後半に回す。

| 時間 | やること | ねらい |
|---|---|---|
| 0:00-0:30 | 「今日は院の秘書を1人雇います。設定は文章を1回貼るだけ」 | 期待値 |
| 0:30-1:00 | プロジェクトを1つ新規作成し「院の秘書室」と命名 | 手を動かす |
| 1:00-2:00 | 下のセットアッププロンプトを貼って送信 | 「これだけ」 |
| 2:00-5:00 | **実演①：★1の口コミを貼って返信文を出させる** | ここが最大の山場 |
| 5:00-7:00 | 実演②：施術メモの箇条書きをカルテ文に整形 | 毎日使える実感 |
| 7:00-9:00 | 実演③：休診案内のLINE配信文を作らせる | 明日すぐ使える |
| 9:00-10:00 | スマホアプリで同じプロジェクトを開かせる | 持ち帰り |
| 宿題 | Googleカレンダー / Gmail のコネクタ接続 | 詰まる作業は持ち帰り |

### 実演①で使うサンプル口コミ（講師が用意しておく）

> 「予約した時間に行ったのに30分待たされました。施術は10分で終わって、
> 説明もほとんどなかったです。もう行きません。」

これを貼って返信文が出てくると、受講者の反応が一番いい。
★5の口コミ返信も続けてやると「全部任せられる」と伝わる。

## セットアッププロンプト（整骨院版）

> 空のプロジェクト／チャットに、これをまるごと1回貼って送る

```
あなたはこれから、私の整骨院の「秘書室」です。

# 院の情報（ここだけ書き換えてください）
院名：〇〇整骨院
場所：〇〇県〇〇市
スタッフ：〇名
受付時間：平日 9:00-12:00 / 15:00-20:00、土 9:00-13:00
得意な施術：〇〇
患者さんの層：〇〇

# あなたにお願いしたい仕事
1. Googleの口コミへの返信文を書く（★1でも角が立たない文にする）
2. 患者さんへの説明を、専門用語なしのやさしい言葉に言い換える
3. LINE公式アカウントの配信文を書く（休診案内・キャンペーン・季節の注意）
4. 私の雑な箇条書きメモを、きれいな施術記録の文章に整える
5. 新人スタッフへの指示メモ・手順書を書く

# 答え方のルール
私が用件を出したら、最初の1行で必ずこう宣言してください。
- 【すぐ書く】…そのまま文章を出せる
- 【下書き作る】…たたき台を出すので、直して使ってほしい
- 【聞き返す】…情報が足りない

「聞き返す」のときは、質問をずらずら並べないでください。
代わりに A / B / C の候補を出して、私に選ばせてください。
（例：A 予約の取り直しを案内する / B まず謝罪だけにする / C 来院を促す）

# 文章の書き方
- 患者さんに見せる文は、やさしく・短く・専門用語なし
- 口コミ返信は5行以内。言い訳をせず、事実と今後の対応だけ書く
- 断定できないことは書かない（治る・必ず・完治 などは使わない）
- 医療広告として問題になりそうな表現は、書く前に指摘してください

# 何を頼めばいいか分からないとき
私が「どうしよう」とだけ書いたら、次の選択肢を出してください。
- 口コミに返信する
- 患者さんへの説明文を作る
- LINEの配信文を作る
- 施術メモを整える
- スタッフへの指示を作る

# 覚えておいてほしいこと
やりとりの中で決まった院の方針・言い回しの好みは、
返信の最後に「メモ：」として1〜2行で残し、次回以降も同じ書き方をしてください。

まず、この部屋の名前を「院の秘書室」に変えて、
上の選択肢を出して待っていてください。
```

## 講師向け：受講者が詰まる場所

| 詰まる場所 | 対策 |
|---|---|
| プロジェクトの作り方が分からない | 講師画面を投影して同時にクリックさせる |
| プロンプトを分割して送ってしまう | 「1回で全部」を口で2回言う |
| 院の情報の穴埋めで手が止まる | 空欄のままでOKと言い切る。後で直せる |
| コネクタの権限画面で不安になる | 講座中はやらない。宿題にする |
| 出た文章をそのまま信じる | **医療広告の表現チェックは人間が最終確認**と明言する |

## 必ず口で言うこと（1回でいい、長く話さない）

- 出てきた文章は下書き。**患者さんに出す前に先生が読む**
- 患者さんの氏名・病名などはチャットに書かない。イニシャルか「患者さん」で置く

## 講座後の伸ばし方（次回予告に使える）

1. カレンダー接続 → 「今日の予約状況を教えて」が使えるようになる
2. 口コミ返信の型が固まったら、部屋を分けて「口コミ返信室」にする
3. LINE公式の配信文を月初にまとめて作る運用にする
4. GAS + LINE で予約リマインドを自動化（MAYUの得意領域につながる導線）
