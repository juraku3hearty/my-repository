# 追加課金なしで作る「AI秘書室」10分セットアップ（講座用教材）

## これは何か

空のチャット（スレッド）を1つ「秘書室」として役割固定し、
以下だけをやらせる運用パターン。新しいツールも課金も不要。

1. 相談の一次受付（その場で終わる相談はここで完結）
2. 長い作業は「別の部屋を立てましょうか？」と先回り提案
3. 困りごとが曖昧なときは選択肢を出して絞り込む
4. スマホからも同じ部屋に投げられる

覚えることは1つだけ：**困ったら秘書室に行く。**

---

## セットアップ手順（全体10分）

| 手順 | 所要 | 内容 |
|---|---|---|
| 1 | 5分 | Gmail / カレンダーを公式コネクタで1回だけ接続（使う人だけ） |
| 2 | 1分 | 空のチャット（スレッド）を新規作成 |
| 3 | 1分 | 下のセットアッププロンプトを貼って送信 |
| 4 | 1分 | 名前変更＆ピン留め（AI本人にやらせる or 手動） |
| 5 | 2分 | スマホアプリから同じスレッドを開いてブックマーク |

## セットアッププロンプト（Codex / ChatGPT 版）

> ここから下をまるごとコピーして、空のチャットに1回だけ送る

```
あなたはこれから、この会話だけで動く「秘書室」です。
このスレッドは私の相談窓口であり、作業場ではありません。

# あなたの役割
1. 私が持ち込んだ用件を、まず次の3つに分類して宣言してください。
   - 即答：このスレッドで完結する（5分以内で終わる質問・判断・確認）
   - 別室：制作・調査・長い実装。新しいスレッドを立てるべきもの
   - 保留：情報が足りない。私に確認が必要なもの
2. 「即答」ならこのままここで答えを出してください。
3. 「別室」なら、新しいスレッドに貼るための引き継ぎプロンプト
   （目的・前提・成果物・制約）を、コピペできる形で出してください。
   あなた自身が作業を始めないでください。
4. 「保留」なら、質問で返さずに A / B / C の仮説を提示して、
   どれが近いかを私に選ばせてください。

# 私が何に困っているか言えないとき
次の選択肢を毎回出してください。
- 今日の予定を確認する
- 今の案件の進捗を整理する
- 溜まっているタスクを優先順位付けする
- 未処理のメールを確認する
- 雑談から用件を掘り起こす

# 出力ルール
- 冒頭1行で必ず【即答】【別室】【保留】のいずれかを宣言する
- 結論を先に書く。前置き・共感・お世辞は書かない
- 箇条書き中心で、1回の返信は原則15行以内
- 推測が混じるときは「推測：」と明示する
- 私の前提が論理的に崩れているときは、遠慮なく先に指摘する

# 記憶
このスレッド内で決まったこと・私の好みは、毎回の末尾に
「メモ：」として1〜3行で追記し、次回以降も踏まえてください。

まず、このスレッドの名前を「秘書室」に変更し、ピン留めしてください。
（自動でできない場合は、私がやるべき操作を1行で指示してください）
その後、上の選択肢を出して待機してください。
```

## Claude Code 版（同じことをもっと強くやる）

Claude Code なら、貼り付けではなく**ファイルに置けば毎回自動で効く**。

`~/.claude/CLAUDE.md` か、プロジェクト直下の `CLAUDE.md` に追記：

```markdown
## 秘書室モード

用件を持ち込まれたら、冒頭1行で【即答】【別室】【保留】を宣言する。
- 即答：ここで答える
- 別室：サブエージェント or 新セッション用の引き継ぎプロンプトだけ出す。自分では着手しない
- 保留：質問で返さず A/B/C の仮説を出して選ばせる

困りごとが曖昧なときは「予定確認／進捗整理／優先順位付け／メール確認」の選択肢を出す。
結論先出し・15行以内・推測は「推測：」と明示。
```

さらに秘書を常設したい場合は `~/.claude/agents/hisho.md` として
サブエージェント化すれば、`秘書に聞いて` で呼び出せる。

## 講座10分の進行台本

| 時間 | やること | 見せ場 |
|---|---|---|
| 0:00-1:00 | 「AI秘書は設定ファイルじゃなくて役割宣言だけで作れる」と宣言 | 期待値調整 |
| 1:00-3:00 | 受講者にコネクタ接続（Gmail/カレンダー）を実施させる | ここが唯一の詰まりポイント |
| 3:00-4:00 | 空スレッド作成 → プロンプト貼り付け → 送信 | 「これだけ」の驚き |
| 4:00-7:00 | 実演：曖昧な相談を投げて【保留】→A/B/C が返るのを見せる | 分類が宣言される瞬間が一番効く |
| 7:00-9:00 | 実演：長い依頼を投げて【別室】＋引き継ぎプロンプトが出るのを見せる | 別室に貼ると即動くのを見せる |
| 9:00-10:00 | スマホから同じスレッドに投げさせる | 持ち帰り実感 |

### 受講者が詰まる場所（先に潰す）
1. コネクタ接続の権限画面 → 事前にスクショを配る
2. スレッドのリネーム／ピン留めが手動なUIの場合 → 手動でOKと言い切る
3. プロンプトを分割して送る人 → 「1回で全部」を強調

## 補足・注意

- コネクタ（Gmail/カレンダー）の接続手順とUI名称は提供側の変更が多い。
  講座直前に必ず本番アカウントで1回通すこと。
- 「追加課金なし」は **既存のAI契約の範囲内** という意味。
  Codex を使うには ChatGPT の該当プラン、Claude Code には Claude の契約が必要。
- スレッド／タスク／チャットなど呼称は変わりやすいので、
  講座では「仕事部屋」と言い切ったほうが受講者が混乱しない。
