## 募集ページ（`/lp`）で院長の確認が必要な点　2026-10-13 追加

募集ページの文面は、そのまま**契約前の表示**になります。実際の運用と違うと
景品表示法・特定商取引法の問題になるため、次の1点は公開前に確定してください。

### ★ 「難しい案件は専門家確認」の中身

募集ページに「内容に応じて専門家への確認を行ったうえで回答します」と書いています。
一方で現在の **利用規約 第2条** と **ご相談画面** は、
「個別の判断が必要な場合は、弁護士・行政書士・医師等の有資格者にご相談ください」
＝ **先生ご自身の専門家へ** という書き方になっており、約束の向きが逆です。

どちらが実際の運用か、次のA〜Cから選んでください。選んだ内容に合わせて
募集ページ・利用規約第2条・ご相談画面の3か所を揃えます。

| | 運用 | 募集ページの書き方 |
|---|---|---|
| **A** | 当社が顧問・提携の専門家に確認してから回答する | 現在の文面のままでよい。ただし「誰に」確認するかの体制を社内で確定する |
| **B** | 当社（院長・講師）が講座と実務経験の範囲で確認して回答する。有資格者判断は先生の専門家へ | 「専門家への確認」→「院長の確認」に書き換え |
| **C** | 案件により A と B を使い分ける | 「内容により、院長の確認または専門家への確認を行ったうえで回答します」に書き換え |

※ A を選ぶ場合、回答が法律判断・医学的判断に踏み込むと、弁護士法72条
（非弁行為）や医師法に触れる可能性があります。**A を選ぶなら、回答の範囲を
どこで止めるかを含めて弁護士の確認を強く勧めます。**

## ★ 「会員価格で行政書士・弁護士へ依頼できる」について　2026-10-13 追加

募集ページに載せたいという話が出たが、**確定情報ではないため「構想2」として
構想欄に入れた。会員特典としては表示していない。** 月額料金に含まれないことも明記した。

契約前の表示として出すには、次の5つが決まっている必要がある。

| | 決めること | 誰が |
|---|---|---|
| 1 | ご協力いただく行政書士・弁護士の先生（実在・合意済み） | MAYU／院長 |
| 2 | 会員価格の具体額と、通常価格との差 | 先生と協議 |
| 3 | 依頼契約は誰と誰の間で結ぶか（当社は入らないのが基本） | 先生と協議 |
| 4 | 当社が紹介に関して対価・手数料を受け取るか | **受け取らない方針を推奨** |
| 5 | 紹介の方法（会員が直接連絡するのか、当社が取り次ぐのか） | 先生と協議 |

### 先に弁護士本人に確認すべきこと（推測ではなく、確認事項として）

弁護士・行政書士の側には、紹介や広告についての職務上のルールがある。
**当方が勝手に決められる話ではないため、必ず先生本人に次の2点を聞くこと。**

1. 有料の会員サービスの会員向けに、割引料金を設けることは、先生の側の規程上
   問題ないか
2. 当社が募集ページでその旨を案内することは、先生の側の広告規制上問題ないか

### 当方側で注意する点

- **当社が紹介料・手数料を受け取る形にしない。** 弁護士法27条（非弁提携）の
  論点に入る可能性がある。無償の紹介にとどめるのが安全
- 月額9,800円の対価に「依頼の割引」を含めない。含めると、月額料金の一部が
  法律事務の対価と評価される余地が生まれる
- 「交通事故実務デスクが代理して交渉します」とは書かない（弁護士法72条）

※ 上記は一般的な論点の整理であり、法的な結論ではない。
　 1〜5が固まった段階で、弁護士に全体の構造を確認することを勧める。
