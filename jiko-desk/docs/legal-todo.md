## 募集ページ（`/lp`）で院長の確認が必要な点　2026-10-13 追加

募集ページの文面は、そのまま**契約前の表示**になります。実際の運用と違うと
景品表示法・特定商取引法の問題になるため、次の1点は公開前に確定してください。

### ★ 「難しい案件は専門家確認」の中身

募集ページに「内容に応じて専門家への確認を行ったうえで回答します」と書いています。
一方で現在の **利用規約 第2条** と **ご相談画面** は、
「個別の判断が必要な場合は、弁護士・行政書士・医師等の有資格者にご相談ください」
＝ **先生ご自身の専門家へ** という書き方になっており、約束の向きが逆です。

どちらが実際の運用か、次のA〜Cから選んでください。選んだ内容に合わせて
募集ページ・利用規約第2条・ご相談画面の3か所を揃えます。

| | 運用 | 募集ページの書き方 |
|---|---|---|
| **A** | 当社が顧問・提携の専門家に確認してから回答する | 現在の文面のままでよい。ただし「誰に」確認するかの体制を社内で確定する |
| **B** | 当社（院長・講師）が講座と実務経験の範囲で確認して回答する。有資格者判断は先生の専門家へ | 「専門家への確認」→「院長の確認」に書き換え |
| **C** | 案件により A と B を使い分ける | 「内容により、院長の確認または専門家への確認を行ったうえで回答します」に書き換え |

※ A を選ぶ場合、回答が法律判断・医学的判断に踏み込むと、弁護士法72条
（非弁行為）や医師法に触れる可能性があります。**A を選ぶなら、回答の範囲を
どこで止めるかを含めて弁護士の確認を強く勧めます。**

## 回答の監修者表示について　2026-10-13 追加

元になっている講座は行政書士の先生が話した内容であることが分かった。
これを受けて、回答に**監修者のプロフィール（ネット記事の著者欄と同じ形）**を
出す方針とし、募集ページの画面例に反映した。

### 出す項目

- 確認した先生のお名前・肩書・事務所名
- その先生のご紹介（2行程度）
- 「✓ この回答を確認済み」
- **出典**（元になった講座の回と、話した先生のお名前）
- 確認日

### ★ 必ず分けること：出典 と 確認者

**「元動画が行政書士の話」であることと、「行政書士がこの回答文を確認した」ことは
別である。** 講座の内容を実務向けに整理し直した文章は、要約の過程で元の話と
ずれる可能性がある。

したがって「行政書士 確認済み」と表示してよいのは、
**その先生が、公開するその回答文そのものを確認した場合だけ**である。
元動画が行政書士の話だというだけでこの表示を出すと、景品表示法の優良誤認にあたる。

幸い、システム側はこの条件をすでに満たしている。回答文を書き直すと
`answer_version` が変わり、`approved_version` と一致しなくなるため、
**確認を取り直すまで表示が消える。**

### システム側に必要な追加（本体は未着手）

| | 追加するもの |
|---|---|
| 1 | 監修者テーブル（氏名・肩書・事務所名・紹介文・写真） |
| 2 | ナレッジごとに監修者を紐づける |
| 3 | 出典（講座の回・話した先生）の欄 |
| 4 | 会員画面にプロフィール欄を表示 |
| 5 | 管理画面で監修者を選べるようにする |

いずれも既存の `internal_reviewer` と承認の仕組みの延長で入る。
本体の変更は、募集ページの方向性が固まってから着手する。
