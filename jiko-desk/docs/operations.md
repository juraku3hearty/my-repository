# 運用：バックアップ・保存期間・障害対応

2026-10-12 / スクリプトは `ops/` にある

## 1. バックアップ

| 対象 | 方法 | 頻度 | 保管先 | 世代 |
|---|---|---|---|---|
| 会員・ナレッジDB | `ops/backup.sh`（SQLiteの `.backup`） | 日次 03:00 | VPS内＋Google Drive | 30日 |
| アプリのコード | git（GitHub） | 変更のつど | GitHub | 無期限 |
| 動画・字幕 | Vimeoが原本 | — | — | — |

**ファイルを `cp` でコピーしない。** 書き込み中だと壊れた断面を取ってしまう。
`.backup` を使い、**取ったその場で `PRAGMA integrity_check` を通す。**

```sh
0 3 * * * /path/to/jiko-desk/ops/backup.sh >> /var/log/jiko-backup.log 2>&1
```

### 復元

```sh
ops/restore.sh /var/backups/jiko-desk/demo-20261012-030000.sqlite3.gz
```

このスクリプトは、
1. **いま動いているDBを先に退避する**（復元が間違っていても戻せる）
2. 展開して `integrity_check` を通してから置き換える
3. 置き換え後に会員数を表示する

### 復元テストの結果（2026-10-12 実施）

```
バックアップを取る        228 KB → 圧縮 23 KB、整合性チェック OK、会員22件
本番DBの会員を全削除      0件
復元                      22件に戻った／ナレッジ10件も戻った
壊れたファイルからの復元  整合性チェックで弾かれ、中止された
```

**年に1回は、この復元テストをやり直す。** バックアップは「取れていること」ではなく
「戻せること」を確認しないと意味がない。

## 2. 保存期間と削除

```sh
30 3 * * * /path/to/jiko-desk/ops/purge_logs.sh >> /var/log/jiko-purge.log 2>&1
```

| 対象 | 期間 | 消したあと |
|---|---|---|
| 利用ログ（検索・閲覧・評価・動画クリック・未解決） | **13か月** | 統計は集計済みの値で残す |
| 決済通知の生ログ | **24か月** | 問い合わせ対応と照合のため長め |
| ログイン用トークン | 使用済み・期限切れは即時 | — |
| 回数制限の記録 | 1日 | — |
| 管理者ログインの記録 | 90日 | — |
| 退会から13か月たった会員 | メールアドレスを消し `status='deleted'` に | 会員IDと期間だけ残る（統計用） |

### 削除テストの結果（2026-10-12 実施）

```
14か月前の利用ログを仕込む → 削除された
25か月前の通知を仕込む     → 削除された
使用済みトークン            → 削除された
```

### 症状別の手順

| 症状 | まず見る | 対応 |
|---|---|---|
| Q&Aが開かない | VPSが生きているか（`systemctl status`） | 再起動。1分で戻らなければ会員に連絡 |
| ログインできない | `outbox` にメールが積まれているか | 積まれていればメール送信の問題。積まれていなければアプリの問題 |
| 決済通知が届かない | 管理画面の `警告` に「許可外のIP」が出ていないか | 出ていれば送信元IPが変わった可能性。サポートに確認 |
| 会員の状態がおかしい | `payment_events` の生ログ | 生ログは消さずに残してあるので、そこから再現できる |
| データが壊れた | バックアップの日付 | `ops/restore.sh` で復元。**先に現在のDBが退避される** |
| 不正なアクセスの疑い | `ops_alerts` と `admin_login_log` | 管理者パスワードを変更し、`FLASK_SECRET` を入れ替える（全員ログアウト） |

### 会員への連絡

- **30分以上止まる見込みなら連絡する。** 連絡しないほうが問い合わせが増える
- 連絡先は会員のメールアドレス（`members.email`）
- 文面は「いつから／いつ戻る見込みか／いま何をしているか」の3点に絞る

### 復旧目標（案・要決定）

| | 案 |
|---|---|
| 平日日中（9〜18時） | 4時間以内 |
| 夜間・休日 | 翌営業日 |

> **自院運用のうちはこれで足りる。他院に販売する段階で、規約に書くかどうかを決める。**
