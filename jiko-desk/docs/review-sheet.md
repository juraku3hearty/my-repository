# 院内確認シートの作り方

`tools/make_review_sheet.py` で作る。初回60項目のレビュー結果を反映している。

```
python3 tools/make_review_sheet.py <動画ID> <動画ID> ... <出力先.csv>
```

## なぜ作り直したか

既存の `quality.py`（根拠照合・数値照合・時刻・分量・完全一致の重複）を
初回の60項目に通したところ、**代表が見つけた12件を1件も拾えなかった（0/12）。**

理由はそれぞれ違う。

| 見つかったもの | quality.py が拾えなかった理由 |
|---|---|
| 「1通院あたり8,600円」が誤読を招く | **講師本人がそう言っていた。** 要約は忠実。数値照合も通る |
| 行動→公道 | 誤字は数値でも引用でもない |
| 推測表現8件 | 検査項目に無い |
| 「講座内では示されていません」 | 検査項目に無い |
| 質問の重なり0.74 | 完全一致しか見ていない |
| 要約が逆（一括対応／被害者請求） | 文字としては全部文字起こしに出てくる |
| 月15日の通院を促して見える | 検査項目に無い |

**つまり quality.py は「文字起こしに無いことを書いていないか」しか見ていない。**
忠実だが実務上まずい要約は、設計上そもそも対象外だった。
これは quality.py の欠陥ではなく、別の検査が要るということ。

## シートに自動で付くもの

### ★ 単独で判断できる（最初に見る）

| 印 | 中身 |
|---|---|
| 推測表現 | 「可能性があります」「と考えられます」など。断定できないなら、そう書くべき |
| 勧誘に見える | 通院・来院を促す言い回し、慰謝料を最大化する言い回し |
| 誤字候補 | 行動→公道、正骨院→整骨院、医者料→慰謝料 など、文字起こし由来の聞き取り違い |

### ★ 重なり（相手の質問文が同じ行にある）

同じシート内の項目、および**すでに承認済みの項目**との重なりを測る。
初回に「医師の同意」で2件が別々の答えを出していたため入れた。
相手の質問文を同じ行に出しているので、探しに行かなくていい。

重なりは本体と同じ採点（containment）で測る。
ただし「交通事故」「患者」「メリット」「は何ですか」のような
どの質問にも入る言葉は外してから測る。外さないと中身が別でも引っかかる。

### 印 数字・条件が対

- **数字** … 金額・日数・期間・割合が入っている。間違えると直接事故になる
- **条件が対** … 一括対応／被害者請求／損保 が2つ以上出てくる。
  初回に要約の向きが逆になった例があったため

### 最初から出さないもの

「示されていません」「言及されていません」で終わる回答は、
検索で出てきても役に立たないのでシートに載せない。初回の KB-1109352698-015 がこれ。

## 並び順

1. ★ 単独で判断できるもの
2. ★ 重なり（比較が要る）
3. 印 数字・条件が対
4. 印なし

上から順に見ていけば、重いものから片づく。

## 機械では拾えないもの（代表の目が要る）

- **講師の説明自体が誤解を招く形だった場合**（8,600円）
- **講師が話していない補足が要る場合**（交通費）
- **実務上まずい書き方**（通院を促して見える）

ここは自動化できない。だからこそ、上の①〜④で機械が拾えるものを先に落としておく。

## 次のシート

**`data/review-02-自賠責A.csv`（96項目）**

すでに作ってある束 `out/①自賠責保険A_100件.csv` に、あとから検査と並べ替えをかけたもの。
新しく動画を選び直してはいない。束は24本の動画から自賠責のテーマで集めたもの。

| 元 | 100件 |
|---|---|
| 初回60件で確認済み | −4件 |
| 回答になっていない | −0件 |
| **出力** | **96件** |

| 区分 | 件数 |
|---|---|
| ① ★ 単独で判断できる | 7 |
| ② ★ 重なり | 50 |
| ③ 印 数字・条件が対 | 20 |
| ④ 印なし | 19 |

重なりが50件と多いが、これは束の性質。24本の動画が同じテーマを扱っているため、
近い質問が実際に並んでいる。読むより「重複」と入れる方が速い。

## 束の順番

| | ファイル | 件数 |
|---|---|---|
| 初回 | `out/院内確認シート.csv` | 60（済52 / 要修正8） |
| **第二弾** | `out/①自賠責保険A_100件.csv` | 100 |
| 第三弾 | `out/②自賠責保険B_93件.csv` | 93 |
| 第四弾 | `out/③保険会社対応と初診_109件.csv` | 109 |
| 第五弾 | `out/④患者説明と請求実務_93件.csv` | 93 |
| 第六弾 | `out/⑤任意保険と施術_94件.csv` | 94 |
| 第七弾 | `out/⑥示談と文書と打切り_104件.csv` | 104 |

次を作るときは、同じやり方でかける。

```
python3 tools/make_review_sheet.py --from-csv "out/②自賠責保険B_93件.csv" data/review-03-自賠責B.csv
```

束どうしの重なりも見たい場合は、確認済みのシートを `data/review-round1.csv` に
足していけば、新しい束を作るときに自動で突き合わせる。

## 重なりの測り方

束がテーマ別だと、全部の質問に「自賠責」が入る。固定の除外語リストでは外せないので、
**束の中で4分の1以上の質問に出てくる文字のつながりは数えない。**
これで、テーマ語ではなく中身が重なっているものだけが出る。

## 交通費の件（解決済み 2026-10-15）

初回の KB-1060102035-005「交通費が抜けてる」は、講師の発言に交通費が無いため
保留にしていた。第二弾の束を作る過程で、別の講座に根拠が見つかった。

> KB-1185184467-027（2026.4.21 行政書士による交通事故講座）
> 「120万円は総額ですと。治療費、医者料、交通費、休業損害、全てが含まれる大きな袋
> というふうに書かせていただいておりますけども」

同趣旨の発言は KB-1165673551-006、KB-1185184467-010/-011 にもある。
したがって「講座にもとづく」の範囲内で交通費を足せる。代表の補足として扱う必要はない。
