# 募集ページ 素材リスト

募集ページの〈 〉になっている箇所は、**素材をいただいてから記入する**。
推測では書かない。いただけなかった項目は、その行ごと消す。

## 1. 院長紹介（必須）

| | 項目 | 形式 | 状態 |
|---|---|---|---|
| ① | 顔写真 | 縦長（縦3：横4）1枚。JPGかPNG | 未 |
| ② | お名前と肩書 | テキスト | 未 |
| ③ | 資格と取得年 | 例「柔道整復師（2008年）」 | 未 |
| ④ | 開業年 | 例「2012年」 | 未 |
| ⑤ | 交通事故実務講座の本数と公開開始年 | 例「全40本／2024年〜」 | 未 |
| ⑥ | 無料セミナーの開催回数と期間 | 例「通算◯回／2022年〜」 | 未 |
| ⑦ | ご経歴 | 3〜5行。交通事故対応に取り組んだきっかけを含む | 未 |

**⑤⑥は数えられる事実だけを書く。** 「多数」「多くの先生」といった表現は使わない。
数が出せない場合は、その行を消して文章の中で触れるにとどめる。

## 2. 監修者（回答に出す先生）

Q&Aの回答の下に出すプロフィール。**確認してくださる先生ごとに1組。**

| | 項目 | 形式 |
|---|---|---|
| ① | 顔写真 | 正方形1枚（丸く切り抜いて表示） |
| ② | お名前 | テキスト |
| ③ | 肩書と事務所名 | 例「行政書士／◯◯行政書士事務所」 |
| ④ | ご紹介 | 2行程度。交通事故分野の経歴 |
| ⑤ | 掲載の同意 | **お名前・写真・紹介文を会員向けに掲載することへの同意** |

⑤は必ず取ること。先生の側には広告についての規程があるため、
掲載内容は先生に確認いただいてから載せる。

## 3. 動画（会員に見せるもの）

| | 項目 |
|---|---|
| ① | 会員に公開する動画の一覧（Vimeoの番号とタイトル） |
| ② | 各動画がどのQ&Aに対応するか |

**非公開の動画は、会員画面にもLPにも出さない。**
Q&Aの「解説動画を見る」ボタンは、公開している動画があるときだけ表示する。
内部の出典（どの講座のどこが元か）は管理画面にだけ持ち、会員には出さない。

## 4. お知らせ・グループ相談（会員トップに出すもの）

いまはダミー。実際に出すものが決まったら差し替える。
**開催が決まっていないものを、決まったこととして書かない。**
