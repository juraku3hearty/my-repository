# 交通事故実務デスク 会員向けQ&Aアプリ（雛形）

ダミーデータで動く雛形です。実データ（`jiko-desk/data/jiko.sqlite3`）との接続は、
院長の確認が一巡してから行います。

## 起動

```bash
pip3 install flask
cd jiko-desk/webapp
python3 seed_dummy.py      # ダミーデータ作成（demo.sqlite3）
PORT=5001 python3 app.py
```

| URL | 画面 | 想定利用者 |
|---|---|---|
| `/` | 質問画面 | 会員（整骨院スタッフ） |
| `/consult` | 相談案内 | 会員 |
| `/admin/analytics` | 分析画面 | 運営者 |
| `/admin/knowledge` | ナレッジ管理画面 | 管理者（院長・MAYU） |

管理画面のパスワードは環境変数 `ADMIN_PASSWORD`（既定 `demo`）。

## 設計上の約束

1. **回答をAIに生成させない。** 検索して、人が確認した文章をそのまま表示する。
   AIが作文しないので、未確認の情報を補うことが構造的に起こらない。
   （`app.py` の `search_items()` は文字の重なりで並べ替えるだけ。LLM呼び出しは無い）
2. **会員に出るのは `publish_status = '公開可'` のナレッジだけ。**
   一覧表示も一括ダウンロードも用意しない。検索語が空のときは何も返さない。
3. **ログは記録前にマスキングする。** 電話番号・メール・住所・氏名らしき語・番号を置換し、
   会員IDはソルト付きハッシュのみ保存する（`applog.py`）。保存期間は13か月の想定。

## ファイル

| ファイル | 役割 |
|---|---|
| `app.py` | Flaskアプリ本体（3画面＋フィードバック・動画クリック記録） |
| `applog.py` | 利用ログのマスキングと記録 |
| `seed_dummy.py` | ダミーデータ生成（10件のナレッジ＋90日分のログ） |
| `templates/` | 画面 |
| `static/style.css` | スマホ優先のスタイル |
| `screenshots/` | 画面イメージ |

`demo.sqlite3` は生成物のため、リポジトリには含めない。
