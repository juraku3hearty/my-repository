# サイフォンズ ログイン連携の検証（読み取りのみ）

**この検証では、サイフォンズのファイルもデータベースも一切書き換えません。**

## 手順

### 0. 先にバックアップ（必須・15分）

1. FTPで `public_html/freemember/` を丸ごとダウンロード
2. エックスサーバーのサーバーパネル → phpMyAdmin → サイフォンズのDBを「エクスポート」
3. 両方をGoogle Drive等にも置く

### 1. 検証用フォルダを作る（5分）

FTPで、サイフォンズと同じ場所に**ランダムな名前のフォルダ**を作る。

```
public_html/freemember/_probe_8f3a2c91d4/
```

このフォルダに `.htaccess` `step1.php` `step2.php` を入れる。
`.htaccess` の `〈自分のIP〉` は、自分のグローバルIPに書き換える。
（IPが変わる回線なら、`Require ip` の行を消して、フォルダ名だけで守る）

### 2. step1.php を開く（2分）

```
https://〈ドメイン〉/freemember/_probe_8f3a2c91d4/step1.php
```

表示された内容をそのままコピーして送ってください。

### 3. サイフォンズに検証用アカウントでログインする（3分）

**本番の会員アカウントは使わないでください。** 自分用のテストアカウントを1つ作る。

### 4. 同じブラウザで step2.php を開く（2分）

```
https://〈ドメイン〉/freemember/_probe_8f3a2c91d4/step2.php
```

表示された内容をそのままコピーして送ってください。

### 5. フォルダを削除する（必須・1分）

`_probe_8f3a2c91d4/` を**フォルダごと削除**してください。
消し忘れると、会員のログイン情報が外から見られる可能性があります。

---

## 送ってもらうもの

- step1.php の表示内容（全部）
- step2.php の表示内容（全部）

この2つで、連携方式と退会の自動停止の方法が両方決まります。
