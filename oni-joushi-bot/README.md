# 🔥 鬼上司Bot（鬼頭課長）

カレンダーが空いていると、鬼上司「鬼頭課長」がLINE・メール・カレンダー侵入の3段構えでしつこく詰めてくる業務効率化(?)Bot。

## 1日の攻撃タイムライン（勤務時間 9-18 の場合）

| 時刻 | 攻撃 | チャネル |
|---|---|---|
| 9時 | 本日1発目の説教 | LINE |
| 10時 | 「【至急】カレンダーの件」 | メール |
| 11時 | **勝手にカレンダーに「【緊急】鬼頭課長との面談」が入る**（通知付き）＋メール | カレンダー＋メール |
| 12〜13時 | 「【再送】読んでいるか？」等 | メール（毎時） |
| 14時 | 最終通告（情に訴えてくる） | LINE |
| 15時〜 | それでも毎時メールは止まらない | メール |

- 予定を入れると次の巡回で**褒めてくれる**（照れながら。件名「【人事評価】見直した」のメールで届く＝LINE無料枠を消費しない）
- サボりが日をまたぐと説教レベルが上がる（軽い注意→圧→ブチギレ→呆れ）
- 休日は黙る。ただし**休日おせっかいモード**（デフォルトON）だと、休みなのに予定ゼロの日は「休みなのに何も予定が無いのか！遊びに行け！」と怒られる

## 費用: 0円

- LINE Push は説教にだけ使う: 1日最大2通＋休日1通 ≈ 月70通 → 無料枠200通内（褒めはメールなので枠を食わない）
- メールは GAS 無料枠（1日100通）
- カレンダー通知は無料・無制限
- Gemini は `gemini-2.0-flash-lite` 無料枠。落ちても固定セリフで動き続ける

## セットアップ（献立AIと同じ流れ）

1. LINE Developers でMessaging APIチャネル新規作成 → チャネルアクセストークン発行
2. Google AI Studio で GEMINI_API_KEY 取得
3. GASプロジェクト新規作成 → このフォルダの8ファイルを貼り付け
4. スクリプトプロパティ設定:
   - `LINE_CHANNEL_ACCESS_TOKEN`
   - `GEMINI_API_KEY`
   - `CALENDAR_ID`（省略可。省略時は自分のメインカレンダー）
5. `initialize()` を手動実行（権限承認＋毎時トリガー設置）
6. デプロイ → ウェブアプリ（全員がアクセス可能）→ URLをLINEのWebhookに設定
7. Botを友だち追加して「ヘルプ」と送る（最初の1通でPush先が自動登録される）

動作テストは `testScold()` を実行すると今すぐ1発説教が来る。

## LINEから送れるコマンド（reply なので全部無料）

- `勤務時間 9-18` … 監視する時間枠
- `休み 土日` … 休みの曜日（`休み なし` も可。ただし怒られる）
- `休日モード オン/オフ`
- `メール攻撃 オン/オフ`
- `カレンダー侵入 オン/オフ`
- `設定` … 現在の監視体制を表示
- `ヘルプ`
- それ以外を送ると鬼頭課長が雑談に付き合ってくれる（無料・無制限）
