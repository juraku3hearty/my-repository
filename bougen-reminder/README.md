# 🤬 暴言リマインダー

リマインドが毎回口悪い。でも憎めない。完了したら照れながら褒めてくれる。

## 使い方（LINEに送るだけ）

```
リマインド 明日15時 銀行行く
```

日時は自然な言葉でOK（「30分後 洗濯物」「8/15 請求書送る」など。Geminiが解釈する）。

時間が来ると…

> まだやってへんのか？「銀行行く」！いつやるんや？今やろがい！

- 催促の下に**「✅ やった」ボタン**が付いてくる。タップすると催促が即ストップ（キャラが一言だけ返す。褒めたりはしない）
- 放置すると**30分おきに再攻撃**（最大3回、口調がどんどん強くなる）
- 文面は毎回Geminiが生成するので同じ暴言は二度と来ない

## キャラ（「キャラ 名前」で変更、デフォルトはおばちゃん）

| キャラ | 芸風 |
|---|---|
| おばちゃん | 関西弁で畳みかける。「まだやってへんのか？いつやるんや？」。詰めた後に飴ちゃんくれる系の愛 |
| 秘書 | ツンデレ有能秘書。「…心配してるとかでは、ないですから」 |
| 軍曹 | 全部叫ぶ。「行動開始ィッ！」 |
| 執事 | 完璧な丁寧語のまま煽ってくる。「まさかお忘れでは…ないですよね？」 |

## コマンド一覧（reply なので全部無料）

- `リマインド <いつ> <何を>` … 登録
- `やった` … 完了報告（催促ストップ。ボタンタップでも同じ）
- `リスト` … 登録中の一覧
- `削除 <番号>` … 取り消し
- `キャラ` / `キャラ 軍曹` … キャラ確認・変更
- `ヘルプ`
- それ以外は雑談（キャラが付き合ってくれる。無料・無制限）

## 費用: 0円

- Pushは1件あたり最大3通。無料枠200通/月 ≒ 月66件までフル暴言可能
- 登録・完了・雑談は全部reply = 無料・無制限
- Gemini は `gemini-3.5-flash` 無料枠。落ちても固定セリフで動く

## セットアップ（10〜15分。献立AI・鬼上司Botと同じ流れ）

1. LINE Developers でMessaging APIチャネル新規作成 → チャネルアクセストークン発行
2. Google AI Studio で GEMINI_API_KEY 取得（鬼上司Botと同じキーでOK）
3. GASプロジェクト新規作成 → このフォルダの8ファイルを貼り付け
4. スクリプトプロパティ設定: `LINE_CHANNEL_ACCESS_TOKEN`, `GEMINI_API_KEY`
   （SPREADSHEET_ID は initialize() が自動で作る）
5. `initialize()` を手動実行（権限承認＋5分おきトリガー設置）
6. デプロイ → ウェブアプリ（全員がアクセス可能）→ URLをLINEのWebhookに設定
7. Botを友だち追加して「ヘルプ」と送る

動作テストは `testNag()` を実行すると、今すぐおばちゃんに催促される。
