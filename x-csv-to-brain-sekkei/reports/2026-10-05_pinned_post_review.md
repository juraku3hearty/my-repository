# 固定ポスト案「マニュアルを作っても使われない理由は1つだけです」レビュー

判定：**方向性は正しい。4点を直してから公開。**

## 良い点（そのまま維持）

| 項目 | 評価 |
|---|---|
| 読者が社長に固定されている | ◎ v2のズレ①（宛先不明71%・「社長」の語が90日3件）を解消 |
| 中身が「判断基準の言語化」 | ◎ 入口商品の中核そのもの。ズレ②（作る系の宣伝）を踏んでいない |
| AIを最後に手段として置いた | ◎ `#AIは手段` と一致。制作を主役にしていない |
| 「見立てだけ。解決作業はしません」 | ◎ 入口商品の境界と一致。期待値が範囲外に膨らまない |
| 3種類の判断（例外／程度／順番） | ◎ オリジナルの枠組み。顧問・伴走でも使える資産 |
| A/B/Cの仕分け＋「Cを決めるとA・Bが聞かなくていいに変わる」 | ◎ 記事中で一番強い。禁止事項を決めると自由が増えるという逆説 |
| 「前に作って失敗したマニュアルを捨てないで」 | ◎ 経験者ペルソナの「また失敗するのでは」に正面から答えている |
| 「渡して、回して、詰まりを直す。1往復で十分」 | ◎ 入口商品の完了条件（テスト実行1回＋修正1回）と完全一致 |

## 直す点

### 修正1：CTAが7つある（自分の仕様違反・最優先）

冒頭の仕様に「CTA：判断基準の言語化シート（1個のみ）」と書いてあるが、本文には7つある。

1. オープンチャット→公式LINE→「判断」送信（**3ステップ**）
2. LINEから「相談」→30分Meet
3. 次の記事URL
4. 過去記事URL
5. フォロー
6. 引用で感想（全部リポストします）
7. 周りに渡してもらう

**問題の本質は数ではなく、オープンチャット経由にしていること。**

- 3ステップは、1〜10名の社長（忙しい・LINE公式に抵抗がある層）には重い
- 「手間かけてすみません」と謝っている＝摩擦が不要だと自分で分かっている
- 月2件の入口商品に対し、リスト取りの導線は過剰。ナーチャリングをしないならリストは資産にならない
- **決定的な問題**：1-Cの紹介パートナー（税理士・社労士・制作会社）が、
  自分の顧客をオープンチャットに流す投稿を転送するか？ しない。情報商材の作法に見える

同じ理由で「引用で感想いただければ全部リポストします」も外す。
66,000円の個別サービスを紹介で売る事業の格を下げる。

**対応（推奨A）**
- シートは**Googleスプレッドシートの閲覧専用リンクを本文に直置き**（「コピーして使ってください」）。0ステップ。転送可能
- CTAは **30分「めんどくさいこと相談」の1本**に絞る。LINEまたはDMで「相談」
- リスト取りを捨てる代わりに、摩擦ゼロと転送可能性を取る

**対応（推奨B：リスト取りを残す場合）**
- オープンチャットを廃止し、**公式LINE直リンク1ステップ**にする
- 「受け取れない人が出る」懸念には、LINEが使えない人向けにメール窓口を1行添えて対応

### 修正2：冒頭5行に「何の人か」が無い

1-Cで X＝「紹介されたあとに何の人か確認する場所」と自ら定義している。
つまり固定ポストの主要読者は**すでに温まっている紹介経由の人**。その人の問いは
「この人は何をしてくれる人で、信用できるか」。

現状の冒頭は冷たい読者向けのフックから始まり、何の人かは最後まで出てこない。
90日のプロフィールアクセスは144（1日1.6人）。この希少な訪問者に10分記事を先に読ませると落ちる。

**対応：記事の一番上に以下を置く（フックの前）**

```
小さい会社の「社長が全部抱えてる」をほどく仕事をしています。
従業員1〜10名の店舗・サービス業が専門です。

・小規模事業の裏方を15年（経理・人事・広告・現場）
・社長の1業務を、スタッフが回せる形に引き継ぐ設計をしています
・作るのではなく、どこが詰まっててどこから直すと効くかを見立てます

今日は「マニュアルを作っても使われない理由」の話です。
```

5行で済む。これがあれば、紹介された人はスクロールせずに判断できる。

### 修正3：自力完走の壁を残していない（66,000円が消える）

SKILL.md Step9の「読者が自力で完走してしまい本命商品に来ない危険」に該当する。

記事は壁を正しく見つけている：
> 「そんなん見たら分かるやん」「それはケースバイケースやろ」 ← ここに判断が埋まっている

しかしその直後に、こう解消してしまっている：
> やってみると、だいたい3〜5個のルールに収まります

さらに「新しいマニュアルは作りません／ツールは1つも増やしません／紙とペンでできます」。
読み終えた社長の結論は「自分でできるな」。**払う理由が本文で消えている。**

**対応：STEP3のあとに1段落追加（売り込みではなく事実として書く）**

```
ただ、1つだけ先に言っておきます。

自分の判断を自分で書き出すと、だいたい「当たり前すぎて書かなかったこと」が抜けます。
15年やってる人ほど抜けます。自覚がないから抜けるわけで、見直しても見つかりません。

で、スタッフが止まるのは、その抜けたところだけです。

書いた本人には見えないので、ここは誰かに「それ、なんでそうしてるんですか」と
聞かれないと出てきません。
だから私は、見立てのときに社長の手順を一度全部しゃべってもらいます。
しゃべると出てきます。書くと出てきません。
```

これで「紙とペンでできる」と「それでも第三者が要る」が両立する。
嘘をついていないので、紹介パートナーに渡しても破綻しない。

### 修正4：価格アンカーがゼロ

v2で特定した最大の未使用資産（prof計0の4投稿）が1つも入っていない。
66,000円を判断してもらう文脈が無いと、金額が裸で出る。

**対応：「AIを入れるのは、このあとです」の直前に1段落**

```
順番を逆にすると、何が起きるか。

制作会社に100万円かけた予約システムが、半年で誰も開かなくなった会社がありました。
中身を聞いたら、打ち合わせに来たのは現場を見ていない人で、
現場で何を判断してるかは一度も聞かれていなかった。

毎月10個以上のツールに20万円払って、使われてるのは半分以下、という会社もありました。

道具が悪いわけじゃないです。
判断を決める前に発注したから、現場とズレたまま出来上がった。
判断を言葉にするのが先です。それをやらずに買ったものは、だいたい置き物になります。
```

100万円・月20万円という数字が先に置かれていれば、
30分の相談から66,000円に進む判断が成立する。

## 削ってよい箇所（長さ対策）

- **「先回りで潰しておきます。よくある失敗5つ」**：内容の大半が本文と重複（失敗3＝1往復、失敗5＝判断が先）。
  一番弱いセクションなので、修正1〜4で増える分をここで回収する
- 「次に読むなら」の2本のURLは、記事が存在してから入れる。プレースホルダのまま公開しない

## 残す判断（変えなくていい）

- タイトル「理由は1つだけです」と本文に3種類＋3段階が出てくる矛盾
  → 原因は1つ、対処が複数なので論理は通っている。読み味としては気になるが、
    「1つだけ」の強さを捨てるほうが損。そのまま
- 「その場にいないと判断できない仕事は対象外。残すと決めたものは堂々と残してください」
  → 入口商品の成果の境界（社長に聞かず自走するまでは保証しない）と一致。むしろ重要
