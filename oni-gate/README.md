# 🚪 鬼頭ゲート — 自作のX自動配布システム

Xの投稿に「鬼頭」とリプライした人へ、導入キットのURLを**鬼頭課長本人（風）のDM**で自動送信するゲート。
**GASのみで動く自作品**（Xステップ/SocialDog等の外部サービス・サーバー不要）。「配布の仕組みも自作です」と言える。

## 動き

```
読者が投稿に「鬼頭」とリプライ
  → 10分ごとの巡回が拾う（since_id差分取得＝API読み取り最小）
    → 未配布の人ならDM送信:
       「呼んだか。鬼頭だ。鬼上司Botの導入キットを渡す。…」
    → DMが閉じてる人には公開リプライで案内（リンクは載せない）
    → 配布ログはスプレッドシートに記録（二重送信防止・リスト資産）
```

## 必要なもの

1. **X Developerアカウント**（発信用Xアカウントでログイン）
2. アプリを作成し、**App permissions を「Read, Write, and Direct Messages」に設定**
3. ⚠️ 権限を変更したら **Access Token を必ず Regenerate**（変更前のトークンではDMが送れない）
4. 4つのキーを控える: Consumer Key / Consumer Secret / Access Token / Access Token Secret
5. 課金プラン: 読み取り（メンション巡回）と書き込み（DM）に従量課金がかかる。月数ドル目安

## セットアップ

1. GASプロジェクト新規作成 →「鬼頭ゲート」→ この5ファイルを貼り付け
2. スクリプトプロパティに5つ設定:
   - `X_CONSUMER_KEY` / `X_CONSUMER_SECRET` / `X_ACCESS_TOKEN` / `X_ACCESS_TOKEN_SECRET`
   - `KIT_URL` … 配布キットのURL（Google Drive共有フォルダ等）
3. `initialize()` を実行 → ログに「X認証OK: @ユーザー名」と出たら成功
4. 動作テスト: 別アカウント（家族のでOK）から自分の適当な投稿に「鬼頭」とリプライ → `testPatrol()` 実行 → DMが届くか確認

## 設定変更（00_Config.js）

- `GATE_KEYWORD` … 反応キーワード（デフォルト「鬼頭」）
- `POLL_MINUTES` … 巡回間隔。短いほど反応が速いが読み取り課金が増える（デフォルト10分）
- `DM_TEXT` … DMの文面（鬼頭課長の口調）
- `REPLY_FALLBACK` … DM不達時の公開リプライ文面

## 注意

- DMはXの仕様上、相手が「全員からDM受信」をオフにしていて、かつこちらをフォローしていない場合は届かない → その場合は自動で公開リプライに切り替えて案内する
- 1巡回ごとに2秒間隔で送信（スパム判定対策）
- 巡回が失敗した回は since_id を進めないので、取りこぼしは次の巡回で回収される
